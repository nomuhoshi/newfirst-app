## 0. 教程形态调整（2026-11-01，优先于下文冲突条款）

项目主人确认：产品是**正常、简洁、能持续往下学的 Python 教程**，不是“一个知识点一组题”的练习软件。下文 §3.2、§4（功能 3、4、5、10）、§4.2、§6.1、§6.3 中与本节冲突的条款，以本节为准。

1. **以教程正文为主**：每页是“短讲解 → 代码例子 → 运行结果”。新概念出现在例子里之前，先用一两句话解释清楚。篇幅按难度分配，不要求每个知识点采用同样数量的讲解卡和题目。
2. **例子可以试一试**：读者可以打开任意例子，修改、运行、恢复原样，也可以不碰直接往下读。改过的例子单独保存草稿，不影响教程里的原文。
3. **学完一组相关知识后，安排一道简短综合练习**。练习可以跳过，不强制答对才能往下学；完成页会列出跳过的练习，随时可以回来做。练习判分先比较输出，再用 `mustUse` 规则检查是否用了本组要练的写法（例如真的用了变量和乘法），并给出具体中文原因。三级提示的最后一级是参考答案。
4. **课程按“课”组织**，每课是几页正文加若干练习；课程路线在首页可见，未上线的课标为“即将推出”，不可进入。
5. 复用：编程键盘、浏览器内真实运行、词义卡（可选）、进度保存。教程内容放在独立的 `content/` 文件中（`course.json` 路线，`l01.json` 等课程）。
6. 撤回此前的“讲解卡 + 选择题 + 自我介绍/画小树/呼叫外星人”等任务方案；“看过答案必须做变化题”的规则不再适用（只在完成页标注“看过答案”）。

## 1. 一句话描述

面向中文编程初学者的免费手机网页应用：通过可展开的知识树、几分钟的引导练习和应用内编程键盘，逐步学习 Python，并在小节末尾完成短程序；英文词源可按需查看。

产品目标是帮助用户利用碎片时间理解、补全和编写简单程序。首发验证基础学习闭环及手机编辑体验，不承诺仅靠选择题即可掌握编程。

## 2. 使用者

- 中文母语、没有基础或基础薄弱的初学者。
- 日常只有几分钟空闲、不方便打开电脑的人。
- 长期覆盖不同行业与学习目的；首发实际提供“编程基础＋数据处理入门”一条路线。
- 第一批测试者为项目主人及身边约四名同学。开发者本人是新手，需要看得懂项目结构和关键代码。

已确认的方向：手机优先、中文讲解、用途导向的知识树、词源可选、英文按钮、内置编程键盘。用户同意由产品搭档安排练习层级和第一版细节。

产品默认方案：先选学习目的，行业选填；首发只提供一条真实可学习路线，后续增加目标时复用共同基础。

## 3. 使用场景

### 3.1 第一次打开

1. 一句话介绍：“每天几分钟，从看懂代码到写出小程序。”无需注册。
2. 选择学习目的。首发有“从零打基础”“处理简单数据”两个入口，共用基础节点，后者突出数据分支；不得伪装成两套独立课程。
3. 可选学习背景：“学生／科研”“办公／业务”“其他”“暂不填写”。只保存在本机，首发用于显示背景标签，不宣称已有行业专属课程。
4. 进入知识树，突出推荐的第一个节点，点击即可开始。用户可以跳过目的和背景，默认从基础开始。
5. 完成首次小练习后再提供可关闭的“添加到主屏幕”说明，不阻止浏览器直接学习。

### 3.2 每次学习

1. 首页展示“继续学习”“待复习数量”和知识树入口。
2. 点击节点，阅读一屏短讲解和一个例子。
3. 先做一道预测结果题，再做一道短输入或补空题，最后做一道变化练习。
4. 相关代码词旁提供小型词义按钮；点击查看来源、音标、含义和用途，关闭后回原题。
5. 编辑题默认使用内置键盘；可以切换系统键盘，输入内容和选区保留。
6. 提交后提供具体反馈；失败可以修改、看提示或继续其他可学节点，不扣体力，不清空代码。
7. 小节末尾做一个短程序任务。通过后显示完成情况和下一步。

### 3.3 中断与返回

- 每道题提交后立即保存结果；代码编辑采用短延迟自动保存，离开编辑框或切到后台时尽力立即保存。
- 下次打开显示同一节点、题目和代码草稿；无需重做已经提交的题目。
- 有待复习内容时推荐先复习，用户仍可继续新内容。
- 浏览器清除站点数据、无痕模式或更换设备可能导致记录丢失；在设置中用一句中文说明，不承诺永久保存或跨设备同步。

### 4.1 内置键盘与编辑规则

- 主界面、题目和反馈使用中文；主要操作按钮使用简短英文。首次出现提供中文说明，帮助页提供词义与美式音标，按钮上不堆放音标。
- 默认内置键盘，包括英文 QWERTY 字母层、数字／符号层以及编程操作栏；保留切换系统键盘的入口。不要求用户额外安装输入法。
- 主要编辑按钮：Tab、Enter、Backspace、Undo、左右箭头；Shift＋Tab 或单独的退缩进按钮执行相同操作。括号和标点直接用符号。
- 学习按钮：Run、Stop、Hint、Check、Next、Back。默认词义按钮可标为 Meaning。
- Tab 插入四个空格，不插入制表符。选中多行时逐行缩进；退缩进每行最多移除四个行首空格，已有非空格文字不得被删除。
- 默认插入半角字符。输入左括号自动补齐右括号，光标居中；普通单引号、双引号同理。
- 对自动补齐的右括号，再输入同一右括号时跳过现有字符；空的自动配对中退格，同时删除配对。
- 有选区时输入普通字符替换选区；输入左括号或引号包裹选区。移动光标后不得把无关右括号误当成自动配对。第一版不承诺三引号、多行字符串的智能配对。
- Enter 延续当前行缩进；本课程涉及的 if、else、for 语句行末冒号后换行，增加一级缩进。用户始终可以退缩进修正；不做自动改写整段程序。
- Undo 至少支持最近二十次编辑，并恢复相应光标或选区。打开提示、查看词义、运行和切换键盘不能清空草稿。
- 提供当前题目可用的词汇快捷按钮；不得直接暴露该道补空题的正确答案。完整答案通过 Hint 逐级提供。
- 竖屏布局允许收起题目或输出区。内置键盘打开后，当前编辑行必须可见；页面可以竖向滚动，代码区可以单独横向滚动。
- 普通操作按钮点击区至少 44×44 CSS 像素；字母键在窄屏下至少 32 像素宽、44 像素高，不能为了堆满操作栏压缩到难以点击。
- 原生输入框、外接键盘和辅助技术保留可用入口。真机验证抑制系统键盘、切换输入方式、选区和滚动行为；如不能可靠实现，报告具体阻塞，不擅自取消内置键盘。

按钮词汇：Tab /tæb/（制表键）；Shift /ʃɪft/（换挡键）；Enter /ˈentɚ/（回车键）；Backspace /ˈbækspeɪs/（退格键）；Undo /ʌnˈduː/（撤销）；Run /rʌn/（运行）；Stop /stɑːp/（停止）；Hint /hɪnt/（提示）；Check /tʃek/（检查）；Next /nekst/（下一步）；Back /bæk/（返回）；Meaning /ˈmiːnɪŋ/（含义）。tap /tæp/ 是“轻点”，缩进按钮采用 Tab。

### 4.2 判断、提示和复习

- 每题先明确学习目标和正确判据。不得要求英文词源拼写正确才能过关。
- 选择题采用人工编写的干扰项，首发不用在线生成；每个错误选项附对应原因。代码补空保留 Python 大小写要求，不将代码整体转成小写判分。
- 短程序按题目公开的测试数据运行、比较预期输出，接受不同的正确实现，不强制复制参考代码。每个综合任务至少两组测试数据，测试数据通过约定变量提供并在每次执行前重新赋值。
- 文本输出比较只统一换行编码及末尾一个换行，不随意删除行内空格。涉及小数的题目必须约定显示精度，首发尽量选择整数结果，避免浮点比较陷阱。
- “运行成功”与“题目通过”分开显示。一次运行无错误不等于学习任务完成；输出匹配也不被描述为完全掌握编程。
- 提示分三级：指出知识点、提示思路、展示参考解法。看完整解法后该题标为“已查看解答”，还需要完成另一道变化练习才能通过节点。
- 首发先讲后练，不先用陌生缩写考试。错误反馈解释具体原因，保留原代码，避免只有一个红叉。
- 节点状态：未开始、可学习、学习中、已完成、待复习。需要先修的节点可以打开简介查看原因，进入练习前给出先修入口。
- 普通节点三道题最终均完成，且最后一道变化练习未查看完整答案，即标为已完成。首次错误写入待复习集合；同次学习结束前提供一次不同内容的重练。
- 下次学习会话仍推荐上次首次答错的知识点；没有新的错题时不生成重复任务。跨会话复习通过后清除该知识点的待复习状态；再次答错则保留。
- “新会话”默认指距离上次学习活动至少三十分钟后重新进入。每个知识点每会话最多加入一次复习，避免无限重复。首发不用复杂间隔算法，不宣称精确测量掌握程度。

## 5. 明确不做什么

- 不做账号、登录、云端同步、后台业务服务、排行榜、社交、支付、广告或推送。
- 不接入运行时大模型，不自动生成课程或实时 AI 点评。
- 不为所有行业分别制作课程，不展示可以进入却没有内容的假路线。
- 不做完整在线开发环境：没有多文件项目、终端、调试器、第三方包安装或任意文件上传。
- 首发不涉及网络爬取、办公文件读写、绘图库、NumPy、pandas 等外部库。数据处理入门仅使用内置类型和函数。
- 不要求完整英文拼写、词源测验或强制查看词义。
- 不做复杂树形动画、无限缩放、多人协作或横屏专用布局。
- 不承诺 Python 运行资源从未加载也能离线执行，不把预先写好的输出冒充实际运行结果。
- 不承诺本机记录永久保存、不同浏览器自动共享或浏览器页面与主屏幕安装版必然共享记录。
- 不把“没有任何 bug”作为无法验证的发布口号；发布依据是验收清单通过且没有未解决的阻塞问题。

## 6. 内容范围

### 6.1 首发课程默认值

十个节点，八个普通教学节点各三道练习，共二十四道练习；两个综合节点各一个任务，共两个短程序任务。每个普通节点目标用时约三至五分钟，综合任务约五至十分钟；用时是设计目标，需试用验证。

| 节点 | 主题 | 用户学完能做什么 | 先修 |
|---|---|---|---|
| N01 | 输出与执行顺序 | 用 print 显示文字或数字，理解逐行执行 | 无 |
| N02 | 变量与赋值 | 保存一个值并在后面使用 | N01 |
| N03 | 数字与计算 | 做简单运算，区分基本整数和小数 | N02 |
| N04 | 字符串与长度 | 区分文字和数字，用 len 获取字符数量 | N03 |
| N05 | 条件判断 | 用 if／else 根据条件输出不同结果 | N04 |
| N06 | 简单循环 | 用 for 和 range 重复有限次数的操作 | N05 |
| N07 | 基础综合任务 | 完成约三至八行的计数或条件输出程序 | N06 |
| N08 | 列表与取值 | 保存一组数，获取元素和数量 | N07 |
| N09 | 数据汇总 | 用 sum 和 len 计算简单平均值 | N08 |
| N10 | 数据综合任务 | 汇总一组给定数据，再按阈值输出判断 | N09 |

树结构：共同基础分支 N01—N07；数据处理入门分支 N08—N10。显示为竖向可折叠目录及少量连接关系，不制作需要双指缩放的大型画布。节点介绍必须列出本节点内的新概念；索引、比较符号、冒号和缩进等不能在没有解释的情况下突然进入题目。

### 6.2 词义内容

按课程实际出现的词制作约十至十五张卡，首发优先覆盖 print、len、int、float、str、if、else、for、in、range、list、sum。函数定义相关的 def、args 等留到后续真实教授该概念时再加入。

每张卡包含代码词、完整单词或短语、美式国际音标、字面含义、Python 用途、一个最短例子，以及来源。普通单词不用伪造缩写还原；int 等按 integer 的来源说明，音标标注到完整英文词。无法可靠确认的词源标为命名说明，不编造。

### 6.3 内容文件与来源

课程和词义使用本地静态 JSON 内容文件，首发可以分为课程、题目、词义三份，避免把全部内容写死在界面组件中。

| 对象 | 必备字段 |
|---|---|
| 课程节点 | 唯一 ID、标题、所属分支、顺序、先修 ID、学习目标、讲解、示例、题目 ID、关联词 ID |
| 练习 | 唯一 ID、节点 ID、题型、题干、初始代码、可选项、正确判据、错误解释、三级提示、参考解法、变化题 |
| 综合任务 | 上述字段、至少两组输入数据、每组预期输出、注入变量名、允许使用的已教概念 |

内容原创编写并对照 Python 官方教程和标准库文档核实。英文音标使用可靠的美式词典来源，保存来源链接，不编造音标。内容发布前逐条运行课程示例和测试数据。

## 8. 技术约束

### 8.1 架构与发布

- 手机优先的 PWA，即可添加到主屏幕的网页应用；通过 HTTPS 静态托管公开免费发布。
- 无账号、无业务后端、无自建服务器。静态托管负责分发网页和必要运行资源；运行代码在用户浏览器完成。
- 优先采用简单的前端工程和静态内容。由 Claude 提出具体框架、编辑器及版本，先说明为何适合新手，不在产品规格中假定依赖一定可用。
- 不使用付费接口或需要秘密密钥的功能；没有访问统计、用户代码或答题数据上传。第三方资源加载会产生正常网络请求，不能把“无学习数据上传”写成“整个应用不联网”。
- 优先固定版本并将运行资源随静态站点托管；若需要外部资源分发站，列出域名、用途、许可证及离线限制。
- 同时验证主域名和仓库子路径部署，避免资源路径、缓存范围或刷新后路由失效。
- 旧发布方式文档中的 App Store、欧盟地区等信息不构成本项目要求；不据此扩展工作范围。

### 8.2 真实 Python 运行

- 默认候选为 Pyodide，首次方案阶段先验证移动端可行性；不直接固定未核实的最新版本号。
- 运行放在独立工作线程中，避免 Python 同步执行阻塞界面。主线程只接收结构化输出，所有用户输出按文本显示。
- 点击 Run 后真实执行当前代码。每次执行采用新的题目变量作用域；第二组测试数据和下次运行不得复用上次用户变量。
- 运行环境按需加载，不阻止用户先阅读讲解、做点选题；加载中、成功、失败、重试都有清晰状态。加载三十秒仍未完成时给出重试选项，保留学习内容。
- 加载完成后的单次执行上限默认五秒，不把首次下载和初始化算进五秒。界面提供 Stop；停止或超时后终止运行线程，必要时重新初始化，编辑器内容保留。
- 连续输出超过一百行或八 KiB 时停止并说明达到上限；向主线程发送输出需要限制频率，防止输出洪水卡死页面。
- 正在执行时禁止重复启动另一轮；用执行标识忽略旧线程迟到的结果。取消、离开节点或重试不能把旧输出误判到新题。
- 运行出错保留原错误类型、行号及可理解的中文提示。没有输出时显示“程序运行完成，没有输出”，不能展示上一轮输出。
- 首发不支持交互式 input、文件、第三方包或外部网络教学。遇到课程范围外能力清楚说明支持边界，不静默自动安装依赖。
- 工作线程用于保持界面响应，不被宣传为可安全执行恶意代码的完整隔离沙箱。应用不把用户输入拼进网页脚本或渲染为 HTML。

### 8.3 本机数据与离线

- 首发记录量小，使用一种简单本机存储方案即可；数据带结构版本，损坏或版本不兼容时提示并安全恢复，不能白屏。
- 答题立即保存；编辑草稿可使用约三百毫秒防抖，并在页面生命周期事件中尽力保存。保存失败显示可见提示，当前会话继续可用，不伪报“已保存”。
- 已访问后的界面、静态课程、词义和点选题需要可离线访问；首次联网完成缓存后显示离线可用状态。
- Python 运行资源的完整离线缓存暂不作为首发要求。资源不可用时说明需联网加载，阅读和点选仍可继续；不能伪造运行结果。
- 不使用“固定五十 MB”或“七天必定清空”等绝对规则描述所有 iPhone。实际缓存和记录可能被浏览器或系统清理，测试时分别验证浏览器与主屏幕模式。
- 更新缓存不能删除用户进度；不要在编辑中强制刷新。新内容和数据结构变更应具备明确版本处理。

### 8.4 开发顺序

1. **技术验证**：一页、一道编辑题、内置键盘、括号配对与缩进、真实运行、停止和超时，在 iPhone 真机验证。此步无需制作全部课程。
2. **完整学习闭环**：实现一个教学节点及一个短任务、词义浮层、提示、保存和重进；用实际操作验证，再复制内容结构。
3. **课程与路线**：填满十个节点、二十四道练习和两个综合任务，加目标选择、知识树和简单复习。
4. **发布验收**：完成缓存和安装说明、交叉审查、人工测试及免费静态发布准备。

每步提供可运行结果、改动说明、关键代码讲解和人工验证方法；完成一步后记录 git 提交，再推进下一步。首轮只提交方案，不把十个节点当成首次开发任务。没有真机时明确列为待人工验证，不声称已通过。

官方技术参考（2026-11-01 查询）：

- Pyodide 官方工作线程说明：https://pyodide.org/en/stable/usage/webworker.html
- MDN 工作线程终止方法：https://developer.mozilla.org/en-US/docs/Web/API/Worker/terminate
- WebKit 存储策略：https://webkit.org/blog/14403/updates-to-storage-policy/

上述资料分别支持线程中执行、终止线程和存储可能被清理的技术事实；本规格的五秒、三十秒、输出上限等数值属于产品默认参数，并非官方性能保证。实现时应核实所固定版本的官方文档。

**全程只用测试邮箱，不要用正式站的账号。** 页面“我的”页顶部有“测试入口信息”面板，每一步先看它：

- 源码提交 = 本次汇报里的 SHA（d284d54a…）
- 云项目 = `tqdwhtrextqlmctkryyg.supabase.co`（若出现 `aqlcunkmggzzvyavlkjg` 立即停止并告诉我们）
- “最近确认同步”只在本次打开后有值；刷新页面后会重新显示“还没有”，这是正常的（只存在内存里）。

准备：iPhone 与 iPad 各用 Safari 打开预览链接（先别装到主屏幕，最后一项再测）。测试邮箱收验证码（需要你本人操作）。

“游客导入待办损坏”只能用开发者手段制造，真机不要求；自动测试已覆盖（Q0–Q20、WebKit/Chromium 浏览器测试）。
若面板“游客导入待办”显示“已损坏/读取失败”，截图发给我们，按页面按钮操作一次“备份并重新导入”（损坏）或“重试读取”（读取失败），再截图。

## 本表不覆盖（已知限制）
- 微信内置浏览器、其它 iOS 版本；
- 真实邮件验证码发送速率限制；
- 两台设备在同一毫秒级窗口同时处理残留登录凭据的竞争（浏览器没有跨标签原子操作，已记录在 docs/37）；
- “最近确认同步”刷新后清零（仅内存）。

## U7L5 一个一个看（for name in stock、stock[name]）

**讲解**：要把库存表里每一种饮品都看一遍，用 for 遍历字典：for name in stock: 每一轮，name 依次是字典里的一个键（不是值），按字典里的顺序，新增的排在最后。想要这个键对应的值，再写 stock[name]。所以 name 是文字（饮品名），要加起来的数量是 stock[name]。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
for name in stock:
    print(name, stock[name])
```
真实输出：`奶茶 12 ⏎ 果茶 5`

### U7L5-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
for name in stock:
    print(name)
```
真实输出：`奶茶 ⏎ 果茶`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `奶茶 ⏎ 果茶` | ✅ 正确 | for name in stock：每一轮 name 是一个键，依次是 "奶茶"、"果茶"，print(name) 把它们显示出来。 |
| `12 ⏎ 5` | ❌ | name 是键，不是值。要显示值，要写 print(stock[name])。 |
| `奶茶 12 ⏎ 果茶 5` | ❌ | 循环里只有 print(name)，只显示键；要连值一起显示，要写 print(name, stock[name])。 |

提示：for name in 字典：name 依次是每一个键。

### U7L5-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
total = 0
for name in stock:
    total = total + stock[name]
print(total)
```
真实输出：`17`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `17` | ✅ 正确 | 第一轮 name 是 "奶茶"，stock[name] 是 12，total 变成 12；第二轮 name 是 "果茶"，stock[name] 是 5，total 变成 17。 |
| `2` | ❌ | total = total + 1 才是数键的个数；这里每轮加的是 stock[name]，这个键对应的值。 |
| `5` | ❌ | total = stock[name] 才会每轮覆盖、只剩最后一个；这里是 total = total + stock[name]，每轮累加。 |

提示：先 total = 0，每一轮加上这一轮的 stock[name]。

### U7L5-Q3（填空）库存少于 5 杯算“低库存”（正好 5 杯不算）。屏幕要显示低库存有几种：1

```python
stock = {"奶茶": 12, "果茶": 5, "咖啡": 3}
low = 0
for name in stock:
    if stock[name] {0} 5:
        low = low + 1
print(low)
```
标准答案：`<`；期望输出 `1`

| 词块 | 真实运行 | 说明 |
|---|---|---|
| `<` | 显示 1 | ✅ 正确 |
| `<=` | 显示 2 | 果茶正好 5 杯，5 <= 5 成立，也被数进去了，得 2。正好 5 杯不算低库存，要用 <。 |
| `>=` | 显示 2 | 数的是库存不少于 5 杯的：奶茶 12 和果茶 5，得 2，不是低库存。 |

提示：低库存是“少于 5 杯”：只有咖啡（3 杯）。边界：正好 5 杯不算。

### U7L5-Q4（读报错选择）下面的程序想把所有饮品的库存加起来，报了 TypeError。第 4 行怎么改，屏幕才会显示 17？

## U7L6 库存小程序（先问有没有，再问够不够，最后才改）

**讲解**：项目：库存小程序。顾客点了 name（饮品）cups 杯，stock 是库存表。先把规则读清楚：饮品不存在（不在 stock 里），输出“没有这个饮品”，库存不变；库存不足（点的杯数比库存多），输出“库存不足”，库存不变；其余情况，库存减去杯数，输出“成交，剩 N 杯”，正好卖完也算成交；不管哪种情况，最后都用 print(stock) 显示库存表。修的办法：先运行，读报错；改好一处，再运行；全部不报错了，也要对一对每种情况的输出，因为有的错不会报错，只会算错。下面的几处，是按示例的修法逐处修改时可能看到的顺序，你的写法不同，看到的顺序也可能不同。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
name = "咖啡"
cups = 2
stock[name] = stock[name] - cups
print("成交，剩", stock[name], "杯")
print(stock)
```
真实报错：`KeyError`

### U7L6-Q2（读报错选择）上面改好之后，换成点 8 杯果茶（只有 5 杯）。程序不报错，却让果茶剩了 -3 杯。规则：库存不足时，输出“库存不足”，库存不变。第 4 行起改成哪一种？

```python
stock = {"奶茶": 12, "果茶": 5}
name = "果茶"
cups = 8
if name in stock:
    stock[name] = stock[name] - cups
    print("成交，剩", stock[name], "杯")
else:
    print("没有这个饮品")
print(stock)
```
（这道题的程序不报错，只是结果不对，所以没有报错块。）
真实输出：`成交，剩 -3 杯 ⏎ {'奶茶': 12, '果茶': -3}`

期望输出：`库存不足 ⏎ {'奶茶': 12, '果茶': 5}`

| 选项 | 真实运行 | 对错 | 错因 / 解释 |
|---|---|---|---|
| 先问存在，再问杯数是不是比库存多（cups > stock[name]）：多就输出“库存不足”，否则才卖 | 显示 库存不足 ⏎ {'奶茶': 12, '果茶': 5} | ✅ 正确 | 杯数比库存多（8 > 5）时输出“库存不足”，什么都不改，库存仍是 5。顺序也对：先看存在不存在，再看够不够，最后才改库存。 |
| 把比较写成 cups < stock[name]：杯数比库存少就输出“库存不足” | 显示 成交，剩 -3 杯 ⏎ {'奶茶': 12, '果茶': -3} | ❌ | 条件写反了：8 < 5 不成立，走到了 else，显示 成交，剩 -3 杯 / {'奶茶': 12, '果茶': -3}。库存不足应该是杯数比库存多：cups > stock[name]。 |
| 先把库存减掉；减完发现小于 0，再输出“库存不足” | 显示 库存不足 ⏎ {'奶茶': 12, '果茶': -3} | ❌ | 检查得太晚：先减了库存才发现不够，显示 库存不足 / {'奶茶': 12, '果茶': -3}。库存不足时，库存应该保持不变：要先比较、再决定改不改。 |

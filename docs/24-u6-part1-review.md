## 2. 两关的学习目标、前置知识、易踩的坑
| | U6L1 它是什么类型 | U6L2 文字和数字互换 |
|---|---|---|
| **唯一的新概念** | `type()` 能说出一个值的种类；认识 int / float / str / bool 四个名字 | `int()`（文字→整数）和 `str()`（数字→文字） |
| **学完能做到** | 看到 `15`、`"15"`、`30 / 2`、`5 > 3` 能说出各自的种类 | 用 `int()` 让文字参与加法；用 `str()` 把数字拼进文字 |
| **前置知识（学生已经见过）** | U1L4：`30 / 2` 显示 `15.0`；U2L1–L2：引号 = 文字、`"15" + "5"` 得 `155`；U3L1/L3：比较得 True/False、布尔值 | U6L1 的种类概念；U2L2 的文字拼接；U1–U2 的加法 |
| **新出现的语法** | `type(...)`，显示格式 `<class 'int'>` | `int(...)`、`str(...)` |
| **本关没有用到** | float()、input、f-string、字符串乘法 | 同左；`int("3.5")` 的 ValueError 留到后面 |
| **容易踩的坑** | ① `15` 和 `"15"` 看着一样，种类不同；② `30 / 2` 是 `15.0`（float），看着像整数；③ `type()` 显示的是种类，不是值；④ 比较的结果是 bool 不是 int | ① 文字 + 数字会 TypeError（要先 `str()` 或 `int()`）；② 文字 + 文字是**拼接**（`"12" + "8"` = `128`），不是相加；③ `int()` 之后才能加；④ `str()` 的结果是文字，不能再当数字用 |
| **题型递进** | 看懂（P）→ 看懂对比（P）→ 动手（F）→ 换个例子（P，bool） | 看懂（P）→ 动手（F）→ 动手（O）→ 换个例子（P，两种加法对照） |
| **报错怎么出现** | 无 | predict 的程序必须能运行，所以 TypeError 只出现在**填空的错误词块**（学生点错会看到“会报错 TypeError”的解释），不出现在选项里让人误以为程序真会输出它 |

教学顺序理由：先给“种类”这个词（L1），L2 才有东西可换；L2 的 `str()`/`int()` 解决 L1 里学生已经隐约看到的“引号数字”问题。读报错、常见错误类型放 U6L3 以后，那时学生已经亲手触发过一次 TypeError。

## 3.1 U6L1 它是什么类型（type() 和四种类型）

**讲解**：点单屏里的值有不同的“种类”：15 是整数（int），15.5 是小数（float），"15" 是文字（str），True 是布尔（bool）。同样长得像 15，加了引号就是文字。type() 能让 Python 说出一个值的种类，结果长这样：<class 'int'>，引号里的 int 就是种类名。

**示范代码**（讲解页）：
```python
print(type(15))
print(type("15"))
```
真实输出：
```
<class 'int'>
<class 'str'>
```

### U6L1-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
cups = 3
print(type(cups))
```
**标准答案**：`"<class 'int'>"`；**真实输出**：`"<class 'int'>"`

| 选项 | 对错 | 为什么（错因 / 解释） |
|---|---|---|
| `"<class 'int'>"` | ✅ 对 | 3 没有引号，是整数，种类名是 int。 |
| `"<class 'str'>"` | ❌ 错 | cups 里是数字 3，没有引号，不是文字。 |
| `'3'` | ❌ 错 | type() 说的是值的种类，不是值本身。 |

提示/总结：type(值) 显示这个值的种类：<class '种类名'>。

### U6L1-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
a = 15
b = "15"
print(type(a))
print(type(b))
```
**标准答案**：`"<class 'int'>\n<class 'str'>"`；**真实输出**：`"<class 'int'>\n<class 'str'>"`

| 选项 | 对错 | 为什么（错因 / 解释） |
|---|---|---|
| `"<class 'int'>\n<class 'str'>"` | ✅ 对 | a 是数字 15（int）；b 加了引号，是文字（str）。 |
| `"<class 'int'>\n<class 'int'>"` | ❌ 错 | b 的 15 带着引号，是文字，不是整数。 |
| `"<class 'str'>\n<class 'int'>"` | ❌ 错 | 顺序反了：a 没有引号，是整数；b 才有引号。 |

提示/总结：15 和 "15" 看着一样，种类不一样：有引号的是文字。

### U6L1-Q3（填空）屏幕要显示：<class 'float'>。哪一个能做到？

### U6L1-Q4（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
ok = 5 > 3
print(type(ok))
```
**标准答案**：`"<class 'bool'>"`；**真实输出**：`"<class 'bool'>"`

| 选项 | 对错 | 为什么（错因 / 解释） |
|---|---|---|
| `"<class 'bool'>"` | ✅ 对 | 比较的结果是 True 或 False，种类是布尔 bool。 |
| `'True'` | ❌ 错 | type() 说的是种类，不是比较的结果。 |
| `"<class 'int'>"` | ❌ 错 | True / False 不是整数，是布尔 bool。 |

提示/总结：比较的结果（True / False）种类是 bool。

## 3.2 U6L2 文字和数字互换（int() 和 str()）

**讲解**：文字 "15" 和数字 15 不一样：文字不能直接和数字相加，"杯数：" + 3 会出错。int("15") 把文字变成整数，str(3) 把数字变成文字。变换之后，才能用 + 做加法，或者拼进文字里。

**示范代码**（讲解页）：
```python
price = "15"
print(int(price) + 5)
print("杯数：" + str(3))
```
真实输出：
```
20
杯数：3
```

### U6L2-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
price = "15"
print(int(price) + 5)
```
**标准答案**：`'20'`；**真实输出**：`'20'`

| 选项 | 对错 | 为什么（错因 / 解释） |
|---|---|---|
| `'20'` | ✅ 对 | int(price) 先把文字 "15" 变成数字 15，再加 5 得 20。 |
| `'155'` | ❌ 错 | 155 是把 "15" 和 "5" 拼在一起的结果；这里 int() 已经把它变成数字，是做加法。 |
| `'15 + 5'` | ❌ 错 | print 显示的是计算结果，不是算式。 |

提示/总结：int(文字) 得到整数，之后就能做加法。

### U6L2-Q2（填空）屏幕要显示：杯数：3

```python
cups = 3
print("杯数：" + {0})
```
目标输出：`'杯数：3'`；**标准答案**：['str(cups)']；提示：拼进文字里的必须是文字：用 str() 把数字变成文字。

全部词块逐个真实运行（检查有没有漏收的合理解）：

| 词块 | 真实结果 | 判定 | 错因解释 |
|---|---|---|---|
| `str(cups)` | `'杯数：3'` | ✅ 对 | 标准答案 |
| `cups` | `'<TypeError>'` | ❌ 错 | 文字不能直接和数字相加，会报错 TypeError。要先把数字变成文字。 |
| `int(cups)` | `'<TypeError>'` | ❌ 错 | int(3) 还是数字 3，文字加数字照样报错 TypeError。 |

### U6L2-Q3（排序）排好顺序。屏幕显示：20

需要排好的行（标准顺序）：
```python
text = "12"
num = int(text)
total = num + 8
print(total)
```
目标输出：`'20'`；打乱后的显示顺序：[3, 1, 0, 2]；提示：先有文字，再变成整数，再相加，最后显示。

全部 4!=24 种排列逐个真实运行：能得到目标输出的有 **1** 种：[[0, 1, 2, 3]]；题目收录的可接受答案：[[0, 1, 2, 3]]。

### U6L2-Q4（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
a = "12"
b = "8"
print(a + b)
print(int(a) + int(b))
```
**标准答案**：`'128\n20'`；**真实输出**：`'128\n20'`

| 选项 | 对错 | 为什么（错因 / 解释） |
|---|---|---|
| `'128\n20'` | ✅ 对 | 第一行：两段文字拼在一起是 128；第二行：先都变成数字，再相加得 20。 |
| `'20\n20'` | ❌ 错 | 第一行 a + b 是两段文字，会拼在一起得 128，不会相加。 |
| `'128\n128'` | ❌ 错 | 第二行先用 int() 把两个都变成数字，再相加得 20。 |

提示/总结：文字 + 文字 = 拼接；整数 + 整数 = 相加。想相加，先 int()。

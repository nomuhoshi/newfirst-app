# 试玩观察 第 1 轮：欢迎 → 第 2 题

日期：2026-11-04 起　主责：设计师　原型：`spikes/2026-11-04-onboarding-prototype/index.html`（PR #35）
规则：按现行红心规则（答错 −1，5 颗）。这一轮只观察，不加埋点，不做 A/B。

## 找谁
3–5 位没学过 Python 的人，用自己的手机。

## 怎么做
1. 只说一句："这是一个学编程的 App，你自然地用，做到第二题就停。"
2. 打开欢迎页，交给对方。**中途不提示、不解释，也不要求故意答错。**
3. 你只看、只记他实际做了什么。不要点右上角「说明」，不要拖碎碎示范。
4. 到第二题（或对方想停）就结束，再问下面的问题。

## 每人记一行

| 试玩者 | 第一次答错在哪一题（没错写"无"） | 能否自己看懂反馈并点「继续」（是 / 犹豫 X 秒 / 需要帮助） | 是否注意到红心减少；是否因此犹豫或想停 | 有没有自己去拖碎碎 | 其他看到的问题 |
|---|---|---|---|---|---|
| A | | | | | |
| B | | | | | |
| C | | | | | |

## 结束后再问（按顺序，不要引导）
1. "刚才错的那题，你觉得错在哪？"（答错的人才问）
2. "答错之后你注意到什么变了吗？"
3. "下面那个小卡片（碎碎），你注意到它了吗？"
4. "有没有哪一步不知道该点哪里？"

每人记一两句原话，原样写，不要改写。

## 结果怎么用
- 有人看不懂错因或找不到下一步 → 本轮直接修，修完再试。
- **没人答错第一题 → 记「本轮未观察到」**，"首题免扣"降优先级，继续修其他问题。
- 有人明确因为扣心想停 → 把这一行和原话交给负责人；批准后做两个独立预览，唯一差别是"第一题首次答错是否扣一颗红心"。
- "整课免扣"是另一件事，单列，不在本轮。

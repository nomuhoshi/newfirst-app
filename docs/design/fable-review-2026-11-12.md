## 评估原文

结论：界面能用、够稳，但前 60 秒没有吸引力，奖励时刻也很平。设计系统 v3（#47）已经解决了其中一大半，但它只有文档，不进第一版。所以按"第一版就能捡的"和"之后做的"分开列。

### 一、第一版就该改的（改动小，效果最大）

1. **欢迎页三屏太空，没说这个 App 是什么。**
   - 现状：第一屏只有"你好，我是小码！"，要点 3 次才到地图，再点 2 次才看到第一题。
   - 建议：合成一屏，标题写"点一点，学会 Python"，小字写"每关约 2 分钟 · 全程点选 · 免费"，主按钮直接进第一题。方案已在 #35 里。
   - 名字还是"小码"；改名"碎碎"已经批过，没落地。
2. **地图一打开，最显眼的是两个不能点或不该先点的东西。**
   - 顶部是灰掉的"随机练习"和虚线的"登录 / 注册"，真正的入口"从这里开始"只是一个 29px 高的小胶囊。
   - 建议：顶部换成一张"继续学习"主卡（关名 + 一句说明 + 大按钮）。随机练习和登录各缩成一行，放到主卡下面。
3. **选择题三个选项横排，代码被从中间折断。**（已由 #60 修复，见上）
   - `print("欢迎光临！")` 被折成两行。新手会照着折断的样子理解代码，这是教学问题。
   - 建议：手机上竖排整宽，每项至少 64 高，代码不折行。
4. **深色模式的主按钮是浅灰蓝色，单元卡是一大块亮蓝。**
   - 整屏没有铜橙主色，按钮看起来像禁用状态，单元卡反而最抢眼。
   - 建议：主按钮改回铜橙配白字，单元卡改成无底色的站牌。
5. **顶栏只有"0 0 5"三个数字。** 新用户不知道分别是什么。每个数字加单位："0 天""0 XP""5/5"。
6. **"我的"页把 10 种按键音效和一排试听、测试按钮全摊开。** 折成一行"按键音效：J 极简"，点进去再选。测试按钮只在调试模式出现。

### 二、让它"好玩"的动态（现在几乎没有）

1. **答对**：现在只是底部出一条绿条。加三样：对勾弹出（放大到 1.15 再回到 1）、"+10 XP"飞向顶栏、顶栏的 XP 数字跳一下。连对 3 题时，碎碎冒一句话。
2. **进度条前进**：加一道高光扫过，约 300ms。成本最低，每题都能看到。
3. **答错**：选中的卡片左右抖两下，碎碎变橡胶弹一下。文案用"差一点"，不用"错误"。
4. **通关页**：电路从左到右通电，真空管点亮，火花三颗，只播一次。
5. **碎碎现在是左下角一张不动的贴纸。** 至少做三件事：进题时眨眼；停留 8 秒没作答时歪头，提示"卡住了就点我"；答对时跳一下。
6. **按钮按下**：下沉 4px 并去掉底边，80ms。现在的按钮是平的，缺"立体"的手感。
7. 以上动效在系统开启"减少动态效果"时全部降为颜色变化。

### 三、版面问题（排在后面）

- 关卡介绍页的代码框是歪的手机框，和其他页面的风格不是一套，下半屏全空。
- 填空题的词块很小、靠左，下面留了半屏空白。词块应加大到 48 高并居中。
- 背景上的断头电路线是随机散落的，不连到任何节点，看着像没画完。要么连到节点，要么换成点阵。
- 题目上方的橙色"提示"条默认展开，颜色像警告。改成中性色的"知识点"，默认收起。

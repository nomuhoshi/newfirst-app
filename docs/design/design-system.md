## 2. 字体与字号（G3：5 级 × 3 种字重）

字体：`"PingFang SC","Noto Sans CJK SC",system-ui`；代码 `"JetBrains Mono","SF Mono",ui-monospace`，**关闭连字**（`font-variant-ligatures:none`，否则 `>=` 会显示成 ≥，初学者会照抄错）。

| 级别 | 字号/行高 | 字重 | 用在 |
|---|---|---|---|
| display | 28 / 1.25 | 800 | 地图主卡标题、通关标题、统计数字 |
| title | 22 / 1.3 | 800 | 题干、单元名、反馈标题 |
| body | 17 / 1.5 | 600（正文 400） | 选项、关卡名、按钮（800） |
| sub | 15 / 1.5 | 400 | 说明、反馈解释、**代码（等宽 15/26px）** |
| caption | 13 / 1.4 | 600 | 标签、徽章、Tab 文字、元信息 |

字重只用 400 / 600 / 800。禁止 12px 及以下的文字（现状 12/700 全部升到 13/600）。

## 3. 间距、圆角、阴影

- 间距只用 4 的倍数：**4 / 8 / 12 / 16 / 20 / 24 / 32**。页面左右边距手机 16（做题页 20），iPad 32。分组标题上 24、下 8（#45）。
- 圆角只有三种：`--r-s 8`（字母框、输出条）、`--r-m 16`（卡片、按钮、代码块）、`--r-full`（胶囊、焊盘节点）。主卡 20、底部面板顶角 24 是唯二例外。
- 阴影只有两种：卡片 `0 2px 0 var(--line)`（硬边“纸板”感）；可按压按钮 `0 4px 0 <lip>`。不用模糊大阴影（选中当前关可加 `--glow` 光晕）。

## 4. 组件

### 4.1 卡片（全站只有一种，G4、#18、#44）

### 4.3 顶栏 HUD 与体力真空管
- 地图顶栏：品牌真空管 → 连续天数胶囊（火焰 + “3 天”）→ XP 胶囊（闪电 + “120 XP”）→ 体力胶囊（5 支真空管 + “4/5”）。每个数字都带单位（#2）。iPad 上显示品牌字“碎片编程”。
- 真空管轮廓取自 #29 `energy-tube.svg`（玻璃罩 + 灯丝 + 底座引脚），胶囊里每支 14×20。亮 = 灯丝 `--glow` + 28% 光晕；灭 = 描边 45% 透明 + 灯丝虚线。**永远同时显示数字**，不只靠颜色；**不持续闪烁**。
- 恢复倒计时只放在 iPad 侧栏 / 点胶囊后的说明里（“下一格体力 18 分钟后恢复”），不做强制等待界面、不放广告位。
- 课内顶栏：44 关闭 → 进度条（12 高，铜→灯丝渐变，带一道高光）→ 体力胶囊。体力/红心以当时合并的规则为准，设计只负责同一位置、同一组件。

### 4.5 普通题
- 知识点条默认**收起**：44 高 `--surface-2` 一行“知识点：print 输出 ▾”，中性色，不用警示橙（#14、GPT：题面和示例默认收起）。
- 题干 22/800 → 代码块（17/1.7 等宽，18/16 内边距）→ 选项。
- **手机上选项竖排、整宽**，每项 ≥ 64 高，左侧 32×32 字母框，代码选项等宽且 `white-space:nowrap`，不在 token 内折行（#13）；iPad 上题目区 max-width 600 居中，选项最多 2 列（#19）。
- 底栏：52×52 提示按钮（灯泡，次按钮样式）+ 主按钮“检查”；未选时“检查”为禁用样式。

### 4.6 统一反馈面板（#25–#30）
答对、答错是**同一个组件**，结构固定：圆形图标 40 → 标题 22/800 → （答对时）`+10 XP` 绿色徽章 → 一句解释 15 → **运行结果条** → 两个按钮（次按钮 40% 宽 + 反馈色主按钮）。

- 颜色只换一组变量：`--fb / --fb-soft / --fb-text` = ok 或 err；面板顶部 2px 反馈色描边，24 顶角，深色模式底色 = 反馈色 14% 混入 `--surface`（不再是暗红褐，#29）。
- **运行结果放在面板里**，所以面板永远不会遮住运行输出（GPT 要求）；同时题目区 `padding-bottom` = 面板实际高度，题面可以滚动看全。
- 答错文案只解释原因，不出现“答案是：”输入框样式（#21）；“看提示”沿用 #19 的 `hints[]` 逐级提示，不加“答错几次才给答案”的门槛。
- 面板高度跟内容走，最大 50% 视口，超出内部滚动。

行为规格（与 release/rc-1 的自制键盘配套）：
1. **自动缩进**：行尾是 `:` 时回车，新行缩进 = 上一行 + 4 空格；空行回车/退格时退回上一级；`⇥/⇤` 每次 4 空格。缩进参考线随缩进层级画出。
2. **成对符号**：输入 `(`、`"`、`[` 自动补右半边，光标停在中间；右半边已存在时再输入只跳过。
3. **符号栏**固定在键盘最上方，切换 123 层时不变；按键按下态：键帽变 `--copper-soft` + 文字 `--copper-text`，80ms，配现有按键音（不另加开关）。
4. 键盘打开时：任务条、编辑器、运行结果、工具栏必须**全部**在可视区内（可视区 = 视口高 − 键盘高）；编辑器至少显示 4 行；切到系统键盘（⌨︎）时同样按 `visualViewport` 高度重排。
5. iPad：编辑器 max-width 720 居中；横屏时任务说明可放左侧 320 宽侧栏，键盘仍整宽但键帽最大 64。

## U8L1 定义和调用（def、函数体、调用 welcome()）

**讲解**：奶茶店每次开门都要说“欢迎光临”。同一句话写很多遍太麻烦：用 def 给这段程序起个名字，以后喊一下名字就行。（你一直在用的 print(…) 就是别人写好的函数，写 print(…) 就是在调用它。）写法：def welcome(): 这一行是“起名字”，下面缩进的几行是函数体，也就是要做的事。注意：def 只是把做法记下来，这时函数体一行都不会运行，屏幕上什么都不会显示。要让它真正做事，要写 welcome()，名字后面带括号，这叫调用：调用一次，函数体就运行一次；调用两次，就运行两次。名字要先定义、后调用。

讲解示例程序：
```python
def welcome():
    print("欢迎光临")
welcome()
welcome()
```
真实输出：`欢迎光临 ⏎ 欢迎光临`

### U8L1-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
def welcome():
    print("欢迎光临")
print("开店了")
```
真实输出：`开店了`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `开店了` | ✅ 正确 | def 只是把做法记下来，函数体要等到调用才运行；这段程序里没有调用 welcome()。屏幕上只有第 3 行的 print 显示的“开店了”（它没有缩进，不在函数里）。 |
| `欢迎光临 ⏎ 开店了` | ❌ | def 那两行不会自己运行。函数体里的 print 要等到调用 welcome() 才会运行，这段程序从头到尾没有调用。 |
| `欢迎光临` | ❌ | 显示的是第 3 行普通的 print：“开店了”。函数体里的 print 没有运行，因为没有调用 welcome()。 |
| `什么都不显示` | ❌ | 第 3 行的 print 没有缩进，不在函数里，是一行普通的程序，会照常运行，显示“开店了”。 |

提示：def 只是起名字、记做法；看有没有 名字() 这样带括号的调用。

### U8L1-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
def welcome():
    print("欢迎光临")
welcome()
print("请点单")
welcome()
```
真实输出：`欢迎光临 ⏎ 请点单 ⏎ 欢迎光临`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `欢迎光临 ⏎ 请点单 ⏎ 欢迎光临` | ✅ 正确 | 函数在被调用的那一行运行：第 3 行调用 → 欢迎光临；第 4 行 → 请点单；第 5 行再调用一次 → 再显示一次欢迎光临。调用几次，函数体就运行几次。 |
| `欢迎光临 ⏎ 请点单` | ❌ | 第 5 行又调用了一次 welcome()，函数体会再运行一遍，所以欢迎光临显示两次。 |
| `欢迎光临 ⏎ 欢迎光临 ⏎ 请点单` | ❌ | 程序按顺序一行一行运行：第 3 行调用（欢迎光临），第 4 行 print（请点单），第 5 行再调用（欢迎光临）。两次调用之间夹着“请点单”。 |
| `欢迎光临 ⏎ 欢迎光临 ⏎ 欢迎光临 ⏎ 请点单` | ❌ | def 那一行不会运行函数体，不算调用。这段程序只有第 3、5 行两次调用，欢迎光临只显示两次。 |

提示：一行一行往下走：碰到 welcome() 就把函数体运行一遍。

### U8L1-Q3（填空）屏幕要显示：欢迎光临

```python
def welcome():
    print("欢迎光临")
{0}
```
标准答案：`welcome()`；期望输出 `欢迎光临`

| 词块 | 真实运行 | 说明 |
|---|---|---|
| `welcome()` | 显示 欢迎光临 | ✅ 正确 |
| `welcome` | 显示  | 只写名字、不带括号，只是提到了这个函数，没有调用它，函数体不会运行，屏幕上什么都不显示（也不会报错）。调用要带括号。 |

## U8L2 给函数一个参数（参数、传入值）

**讲解**：欢迎光临永远是同一句话。想让同一个函数按不同的饮品工作，就给它留一个空位：def say(drink): 括号里的 drink 叫参数，在函数体里它就像一个变量。调用时，括号里写的值会传进这个空位：say("奶茶") 把 "奶茶" 传给 drink，函数体里用到 drink 的地方就是“奶茶”；say("果茶") 再传一个，同一个函数就得到不一样的结果。每次调用都会重新传值。调用时不给值，Python 会报 TypeError（类型错误）。

讲解示例程序：
```python
def say(drink):
    print("来一杯", drink)
say("奶茶")
say("果茶")
```
真实输出：`来一杯 奶茶 ⏎ 来一杯 果茶`

### U8L2-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
def say(drink):
    print("来一杯", drink)
say("咖啡")
say("果茶")
```
真实输出：`来一杯 咖啡 ⏎ 来一杯 果茶`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `来一杯 咖啡 ⏎ 来一杯 果茶` | ✅ 正确 | 第 3 行调用 say("咖啡")，咖啡传给 drink，显示“来一杯 咖啡”；第 4 行再调用 say("果茶")，这次 drink 是果茶，显示“来一杯 果茶”。 |
| `来一杯 drink ⏎ 来一杯 drink` | ❌ | print 里的 drink 没有引号，是参数这个变量，显示的是传进来的值（咖啡、果茶），不是单词 drink。 |
| `来一杯 咖啡 ⏎ 来一杯 咖啡` | ❌ | 每次调用都会重新传值。第 4 行传的是果茶，drink 这次就是果茶。 |
| `来一杯 果茶 ⏎ 来一杯 咖啡` | ❌ | 程序按顺序运行：先第 3 行传咖啡，再第 4 行传果茶，所以先显示咖啡。 |

提示：每次调用，括号里的值传给参数；函数体里的 drink 就是这一次传进来的值。

### U8L2-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
def pay(price):
    print("应付", price * 2)
tea = 8
pay(tea)
tea = 5
pay(tea)
```
真实输出：`应付 16 ⏎ 应付 10`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `应付 16 ⏎ 应付 10` | ✅ 正确 | 第 4 行调用 pay(tea)，这时 tea 是 8，传给 price，8 × 2 = 16。第 5 行把 tea 改成 5，第 6 行再调用，传进去的是 5，5 × 2 = 10。 |
| `应付 16 ⏎ 应付 16` | ❌ | 每次调用，传进去的是调用那一刻 tea 里的值。第 5 行已经把 tea 改成 5，第 6 行传的是 5，所以是 10。 |
| `应付 8 ⏎ 应付 5` | ❌ | 函数体里写的是 price * 2，要乘 2：8 × 2 = 16，5 × 2 = 10。 |
| `应付 10 ⏎ 应付 10` | ❌ | 函数是在调用的那一行运行的，不是等到最后。第一次调用时 tea 还是 8，得 16，之后 tea 才改成 5。 |

提示：看调用的那一刻变量里是多少：传进去的是值，不是变量名。

```python
def pay({0}):
    print("应付", price * 2)
pay(10)
```
标准答案：`price`；期望输出 `应付 20`

### U8L2-Q4（读报错选择）忘了给 pay 传值，运行报了错。最后一行 TypeError: pay() missing 1 required positional argument: 'price' 是在说什么？

```python
def pay(price):
    print("应付", price * 2)
pay()
```
展示给学生的报错（真实运行，和 CPython 一致，不含 ^ 箭头）：
```
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    pay()
TypeError: pay() missing 1 required positional argument: 'price'
```

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| 调用 pay() 时括号里没给值，参数 price 没有收到 | ✅ 正确 | def pay(price) 留了一个空位 price，调用时必须传一个值进去。第 3 行 pay() 括号里是空的，所以 Python 说“少了 1 个必须给的参数 'price'”。 |
| pay 这个名字还没有定义 | ❌ | 那是 NameError。pay 在第 1 行已经 def 过了；这里报的是 TypeError，说的是调用时少了一个值。 |
| def 那一行少了冒号 | ❌ | 少冒号是 SyntaxError，程序一行都不会运行。这里 def 写得没问题，函数体都定义好了，是第 3 行调用时才出的错。 |
| 函数体没有缩进 | ❌ | 那是 IndentationError。这里函数体的缩进是对的；最后一行写的是 TypeError，说的是调用时少了一个值。 |

提示：missing 1 required argument：少了 1 个必须给的值。看看调用那一行括号里有没有东西。

# U9 小项目：奶茶店点单小票（草稿）

分支 `content/u9-draft`（基于 `content/u8-revise` `9d75e07`）。**草稿，待产品官审题；不接入应用**（接入顺序在 U6 → U7 → U8 之后，且等 pick 真机验收）。
生成：`python3 scripts/make-unit9.py`；校验：`python3 scripts/verify-content.py --extra content/unit9.json`。

## 1. 学习目标

基础线最后一单元，不教新语法，练“把学过的合起来用”和 AI 时代最需要的三件事：

1. **拆需求**：把“做一张小票”拆成数据（菜单用字典、订单用列表）和步骤（循环累加、函数、规则）。
2. **读懂组合程序**：字典 + 列表 + 循环 + 函数 + if 在同一段程序里时，能追出结果、读懂报错指向哪里。
3. **检查 AI 写的程序**：找能让它露馅的输入、判断哪种修复对、修完再试——和样板关同一套动作，放在完整程序上练。

只用 U1–U8 学过的：变量、运算、if/else、for、break、列表（sum、in）、`+=`、字典（查、in、KeyError）、def / 参数 / return / None、函数里的名字外面用不了。不用 f-string、`.items()`、try。

## 3. 校验

## 4. 顺手修的校验工具问题

`scripts/verify/common.py` 生成课程里显示的报错原文时，把每一层位置都写成 `in <module>`。报错发生在函数里时，真实 Python 写的是函数名（`in bill`）。已改成用真实的名字。U1–U8 现有题目的报错都在主程序里，不受影响（U8 带 `--extra` 校验仍失败 0）。另一处：程序在**编译时**就出错（SyntaxError，一行都没运行）时，`real_error` 原来会因为找不到运行位置而自己崩溃（IndexError），所以以前没法出“读 SyntaxError”的 pick 题。现在按真实 Python 的显示返回（没有 Traceback 标题，只有位置、那一行和错误）。现有题目没有用到，不受影响。
**这个修正要随 U9 一起进主线，否则 L4 题 1 的报错原文会对不上。**

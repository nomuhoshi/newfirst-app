# 视觉升级 v2：更立体、电路更复杂

写于 2026-11-04（程序员 Sonnet）。老大看过设计稿后确认沿用「墨蓝实验手账」，只做升级：**更立体、电路更复杂**。颜色、逻辑、课程内容都没动。

## 改了什么
- 六边形节点：加侧面厚度、投影、高光和内刻面；完成的发绿光，当前关发铜色光。
- 单元横幅：带引脚的芯片；状态栏三项数字：凹进去的读数窗；标签栏：当前页亮一条灯。
- 按钮、选项：带底座的立体键，按下陷 3px（原来 1px）。代码块像凹进去的屏；进度条带光；答对/答错反馈条通电发光。
- 电路背景：在原来的稀疏走线旁边加两根平行的总线、4 块带引脚的芯片（U2–U5）、过孔小点。**新元素用新类名（`.bus` `.chip` `.chip-pin` `.chip-ref` `.via-dot`），不计入 `.trace` / `.pad` 的数量限制**，所以 step2 里“线条不超过 8 条”这类检查保持原样。
- 新增色板变量（浅色、深色各一套）：`--g-side` `--g-hi` `--g-shadow` `--g-well` `--g-pin` `--g-lip-*`。
- 矮屏（iPhone 横屏）：节点按比例缩小，入口和当前关仍然同时放得下。

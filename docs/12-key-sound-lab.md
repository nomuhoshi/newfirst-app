## 1. 电路背景：按实际窗口大小生成
项目主人在 iPad 小窗口（约 425×390）里打开，几乎看不到电路。原因：电路原来画在固定的“手机竖屏”尺寸上，窗口形状不同时被裁掉大半。
现在改为按 `window.innerWidth / innerHeight` 生成：7 条路径从左、右、上三个方向进入，4 条带分支，焊点和光点数量不变；窗口变化（旋转、拖动分屏）时重新生成。自动测试验证了 390×844、425×390、横屏 844×390：都有 5–7 条路径、至少 3 个方向、至少 3 条分支、中间留空、路径都在屏幕内。

## 2. 按键音效选择实验室
位置：“我的”页 →“按键音效选择”。A–J 十个原创的矮轴机械键盘方向音效（Web Audio 合成，不下载、不复制任何品牌录音）：

| | 名称 | 方向 | 时长 |
|---|---|---|---|
| A | 清脆矮轴 | 短促、干净、轻微触底声 | 45ms |
| B | 奶油矮轴 | 更柔和，低频稍多 | 75ms |
| C | 轻段落轴 | 按下时有轻微段落感（两段式） | 78ms |
| D | 铝板矮轴 | 清脆，带极短金属感 | 67ms |
| E | 塑料外壳 | 轻巧、偏明亮 | 40ms |
| F | 静音矮轴 | 声音很短、很克制 | 40ms |
| G | 深沉矮轴 | 触底声稍厚 | 90ms |
| H | 弹性垫片 | 柔软，带一点回弹 | 65ms |
| I | 陶瓷清响 | 清亮但不刺耳 | 75ms |
| J | 极简 Tap | 非常短，适合连续点击 | 40ms |

- 响度：用离线渲染实测，十个音效的 RMS 都在 −28 dB 左右，差距 < 0.2 dB，峰值都 < 0.45（不削波）。自动测试要求差距 ≤ 2 dB。
- 连续点击：同时最多 3 个发声，更早的会快速淡出，不会无限叠加（测试连点 60 次）。
- 点击后高亮并保存在本机记录里（`prefs.keySound`），刷新后仍在。
- **暂时不接进答题流程。** 选定后，以选中的声音为基础，再做“点选、放入、撤销、答对、答错、过关”的同系列变化。
- 声音由真正的 click 触发，和“我的”页已经确认能响的测试同一类操作。**能不能在你的 iPhone 上听到，仍要你确认。**

GPT 建议优先听 A、B、D、J（应用操作频繁，声音应短、轻、干净）。

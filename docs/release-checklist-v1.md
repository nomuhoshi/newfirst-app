## 3. iPhone 真机核查清单（老大做，约 20 分钟）

先别点“清除学习记录”、别删主屏幕图标。每步记录：通过 / 不通过、截图、iOS 版本。

1. Safari 新开标签页，输入 `https://nomuhoshi.github.io/newfirst-app/`；先在标签总览里看是否有多个旧的碎片编程标签页，**先别点开**，记数量。
2. “我的 → 自测”：记应用版本、运行方式、存储是否“已持久”、入口网址。
3. 做完一关到结算页，按“继续”回地图；从后台划掉 Safari，再打开同一网址：关卡 / XP / 红心还在吗？
4. 添加到主屏幕：先在 Safari“我的 → 数据与备份”复制进度码；添加图标；从图标打开，粘贴进度码导入；核对进度。
5. 做 U7L1、U7L3、U7L6（含最长的题）：代码块是否被截断、“继续”按钮是否被盖住、解释能否读全。
6. 横屏看一眼；开飞行模式刷新一次：地图能打开。
7. 记录：是否无痕、是否用 Safari 个人资料、“没了”是整份归零还是只有那一关。

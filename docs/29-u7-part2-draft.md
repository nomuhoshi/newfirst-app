## U7L3 先问再取（in、.get()、None 和默认值）

**讲解**：查一个字典里没有的键，会报 KeyError，程序就停了。想不让它停，有两个办法。第一个：先问一问。"咖啡" in stock 问的是：咖啡是不是字典里的一个键，答案是 True 或 False（not in 是反过来问）。注意字典的 in 只看键，不看值：12 是奶茶的数量（值），所以 12 in stock 是 False。配合 if：先问有没有，有才取。第二个：stock.get("咖啡")，查得到时和 stock["咖啡"] 一样给出值，查不到时不报错，给出 None（意思是“没有”）。还可以在逗号后面写一个默认值：stock.get("咖啡", 0)，查不到就用 0；查得到时用的仍然是真实的值，默认值不起作用。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
print("咖啡" in stock)
print(stock.get("咖啡"))
print(stock.get("咖啡", 0))
```
真实输出：`False ⏎ None ⏎ 0`

### U7L3-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
print("奶茶" in stock)
print("咖啡" in stock)
print(12 in stock)
```
真实输出：`True ⏎ False ⏎ False`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `True ⏎ False ⏎ False` | ✅ 正确 | 奶茶是字典的键，True；咖啡不是键，False；12 是奶茶的数量（值），不是键，in 只看键，False。 |
| `True ⏎ False ⏎ True` | ❌ | 最后一行 12 in stock：in 只看键，不看值。12 是值，不是键，是 False。 |
| `False ⏎ False ⏎ False` | ❌ | 第一行 "奶茶" in stock：奶茶是字典里的键，是 True。 |

提示：字典的 in 问的是：这个名字是不是字典里的键。

### U7L3-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
print(stock.get("果茶"))
print(stock.get("咖啡"))
print(stock.get("咖啡", 0))
```
真实输出：`5 ⏎ None ⏎ 0`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `5 ⏎ None ⏎ 0` | ✅ 正确 | 果茶有，给出 5；咖啡没有，没写默认值，给出 None；咖啡没有，写了默认值 0，给出 0。 |
| `5 ⏎ 0 ⏎ 0` | ❌ | 第二行没写默认值：查不到时给出的是 None（意思是“没有”），不是 0。 |
| `5 ⏎ None ⏎ None` | ❌ | 第三行逗号后面的 0 是默认值：查不到咖啡，就用它，显示 0。 |
| `报错` | ❌ | .get() 查不到时不报错：没有默认值给 None，有默认值给默认值。只有 stock["咖啡"] 这种写法才会报 KeyError。 |

提示：.get(键) 查不到给 None；.get(键, 默认值) 查不到给默认值。

### U7L3-Q3（填空）咖啡还没进货。屏幕要显示：没有这个饮品

```python
stock = {"奶茶": 12, "果茶": 5}
name = "咖啡"
if {0}:
    print(stock[name])
else:
    print("没有这个饮品")
```
标准答案：`name in stock`；期望输出 `没有这个饮品`

| 词块 | 真实运行 | 说明 |
|---|---|---|
| `name in stock` | 显示 没有这个饮品 | ✅ 正确 |
| `name not in stock` | 报错 KeyError | 咖啡不在字典里，所以 name not in stock 是 True，程序会去取 stock[name]，结果报 KeyError。要的是“有才取”：用 name in stock，咖啡没有就走 else。 |
| `stock[name]` | 报错 KeyError | if 后面要先得出 True 或 False，可是 stock[name] 自己就要先去查咖啡，查不到当场报 KeyError，根本到不了 if。 |

提示：先问“name 在不在 stock 里”：在才取，不在就走 else。

### U7L3-Q4（读报错选择）咖啡还没进货，字典里没有这个键，下面的程序报了 KeyError。要让屏幕显示 0（而不是报错），第 2 行怎么改？

```python
stock = {"奶茶": 12, "果茶": 5}
print(stock["咖啡"])
```
展示给学生的报错（真实运行，和 CPython 一致，不含 ^ 箭头）：
```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(stock["咖啡"])
KeyError: '咖啡'
```

期望输出：`0`

| 选项 | 真实运行 | 对错 | 错因 / 解释 |
|---|---|---|---|
| 改成：print(stock.get("咖啡", 0)) | 显示 0 | ✅ 正确 | .get() 查不到咖啡不报错，用默认值 0，屏幕显示 0。 |
| 改成：print(stock.get("咖啡")) | 显示 None | ❌ | 不报错了，但显示 None：没写默认值，查不到给 None，不是 0。 |
| 改成：print("咖啡" in stock) | 显示 False | ❌ | 不报错了，但显示 False：in 问的是“在不在”，答案是 True / False，不是数量。 |
| 改成：print(stock.get("果茶", 0)) | 显示 5 | ❌ | 显示 5：查的是果茶，果茶有，用的是真实的值；要查的是咖啡。 |

提示：没有这个键时想要一个默认值：.get(键, 默认值)。

## U7L4 进货与下架（新增、拼错键名、del）

**讲解**：给字典里没有的键写值，就是新增一对：stock["咖啡"] = 8，字典里多了咖啡。写法和上一关的“替换”一样：键已经有，就是替换；键没有，就是新增，Python 不会报错提醒你。所以键名拼错了，也不会报错，而是悄悄多出一个拼错的键，原来的键没动。删掉一对：del stock["果茶"]，键和值一起删掉；要删的键必须存在，否则也会报 KeyError。现在可以直接看整个字典了：print(stock) 显示 {'奶茶': 12, '果茶': 5}，每一对是 '键': 值，文字外面是单引号（Python 习惯这样显示，你写的双引号也可以）。新增的键排在最后面。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
stock["咖啡"] = 8
del stock["果茶"]
print(stock)
```
真实输出：`{'奶茶': 12, '咖啡': 8}`

### U7L4-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
stock["咖啡"] = 8
print(stock)
```
真实输出：`{'奶茶': 12, '果茶': 5, '咖啡': 8}`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `{'奶茶': 12, '果茶': 5, '咖啡': 8}` | ✅ 正确 | 咖啡原来没有，给它写值就是新增一对，排在最后面。 |
| `{'奶茶': 12, '果茶': 5}` | ❌ | 第 2 行已经运行了：给没有的键写值，会把这一对加进去。 |
| `{'咖啡': 8, '奶茶': 12, '果茶': 5}` | ❌ | 新增的键排在最后面，不是最前面。 |
| `报错` | ❌ | 给没有的键写值不会报错，是新增。只有“取”一个没有的键，才会报 KeyError。 |

提示：键没有，写值就是新增；键已经有，写值就是替换。

### U7L4-Q2（选输出）小码想把果茶的库存改成 4，却把“茶”打成了“查”。点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
stock["果查"] = 4
print(stock["果茶"])
print(stock["果查"])
```
真实输出：`5 ⏎ 4`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `5 ⏎ 4` | ✅ 正确 | "果查" 原来没有，写值就是新增一对，不会报错；果茶根本没被改，还是 5。第 4 行查的是新增的 "果查"，是 4。 |
| `4 ⏎ 4` | ❌ | 果茶没有被改：第 2 行写的是 "果查"，是另一个键。 |
| `5 ⏎ 报错` | ❌ | 给没有的键写值不会报错，而是新增了 "果查"，所以第 4 行查得到，是 4。 |

提示：键名拼错了，Python 不会报错：它会新增一个拼错的键。

### U7L4-Q3（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
del stock["果茶"]
print("果茶" in stock)
print(stock.get("果茶", 0))
```
真实输出：`False ⏎ 0`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `False ⏎ 0` | ✅ 正确 | del 把果茶这一对（键和值）一起删了，所以果茶不在字典里（False）；用 .get("果茶", 0) 查，查不到，用默认值 0。 |
| `True ⏎ 5` | ❌ | 第 2 行 del stock["果茶"] 已经运行：键和值都被删掉了，不是只删值。 |
| `False ⏎ None` | ❌ | 第二个 print 写了默认值 0：查不到果茶，就用 0，不是 None。 |
| `报错` | ❌ | 果茶在字典里，del 可以删，不会报错。要删的键不存在才会报 KeyError。 |

提示：del 字典[键]：键和值一起删掉。

### U7L4-Q4（排序）排好顺序。进货 5 杯果茶：字典里没有果茶时，先记成 0，再加上 5，最后显示：5

标准顺序（打乱后让学生排）：
```python
stock = {"奶茶": 12}
if "果茶" not in stock:
    stock["果茶"] = 0
stock["果茶"] = stock["果茶"] + 5
print(stock["果茶"])
```
真实输出：`5`；可接受的排列共 1 种（穷举所有 120 种排列核对）。提示：先有字典；再检查有没有果茶，没有就记成 0；然后加 5；最后显示。

# 产品想法：碎片编程 · 词源加练

> ⚠️ 本文是最初的想法，已被 `spec/SPEC.md` v0.1 取代：范围扩展为 10 节微型课程，词源改为可选词义卡。保留作历史记录。

## 一句话
用手机、利用碎片时间、**点选而不是打字**来学 Python；第一版只做「词源加练」。

## 名字
- 中文：碎片编程
- 英文候选：Snippet / Codelet（还没定）

## 词源加练是什么
Python 里有很多缩写（`len`、`def`、`elif`、`int`、`str`、`args`……）。看不懂缩写，就记不住。
这个功能：**给一个缩写，让用户还原成完整的英文单词**，并显示：
- 完整单词
- **美式国际音标**
- 意思（单词解释单词；如果是短语就解释短语）
- 它在 Python 里是做什么的

## 第一版的想法（草案，待 GPT 帮我细化）
- 题目形式：给出缩写，从几个选项里点选完整单词（不用键盘）。
- 答完显示音标、意思、Python 里的用途、一个很短的代码例子。
- 底下有一个“运行看看”按钮，用 Pyodide 在浏览器里执行这一行代码。
- 内容：先放 20–50 个最常见的缩写/关键字/内置函数（数量待定）。
- 没有账号、没有服务器、没有数据上传；进度只存在手机本地。

## 为什么选这个
- 这是我自己真正会用的学习方式。
- 功能小，规则清楚，一个新手 + AI 几周能做完。
- 没有账号和后端，部署最简单。

## 暂时不做（先不记，避免第一版变大）
- 题型分类、目标输出图
- 账号、排行榜、社交
- 推送提醒
- 物理公式复习（以后可以作为同一个应用里的另一个“内容包”，不要做成另一个应用）

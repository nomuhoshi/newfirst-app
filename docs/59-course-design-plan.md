### U6 样板：U6L2 文字变数字（int()）

**开场说明**：点单屏读进来的“15”其实是文字 "15"，不能直接拿来算。int("15") 把它变成整数 15，就能算了。

**开场示例**：
```python
price = "15"
print(int(price) + 5)
```

**第 1 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
cups = "3"
print(int(cups) + 1)
```

- ✅ `4`：int(cups) 把文字 "3" 变成整数 3，3 + 1 得 4。
- ❌ `31`：int() 已经把 "3" 变成整数，这里做的是加法，不是把文字接在一起。
- ❌ `3`：变成整数 3 之后还要加 1。

**第 2 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
a = "12"
b = "8"
print(a + b)
print(int(a) + int(b))
```

- ✅ `128 ⏎ 20`：第一行是两段文字相接，得 128；第二行先都变成整数再相加，得 20。
- ❌ `20 ⏎ 20`：a 和 b 带引号，是文字。文字用 + 是接在一起，不是加法。
- ❌ `128 ⏎ 128`：第二行用了 int()，12 和 8 已经是整数，+ 是加法。

**第 3 题（填空）** price 是文字 "12"。要算两杯的钱，屏幕显示：24

```python
price = "12"
total = ____ * 2
print(total)
```

- ✅ `int(price)`
- ❌ `price`：price 还是文字，文字 * 2 是把它重复两遍，会显示 1212。
- ❌ `"price"`：加了引号就不是变量了，是 price 这五个字母，重复两遍显示 priceprice。

**第 4 题（排序）** 排好顺序。屏幕显示：20

可选的行（打乱显示）：
```python
total = num + 8
text = "12"
print(total)
num = int(text)
```

正确顺序：
```python
text = "12"
num = int(text)
total = num + 8
print(total)
```

**第 5 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
n = int("7")
print(n * 2)
print("7" * 2)
```

- ✅ `14 ⏎ 77`：n 是整数 7，乘 2 得 14；"7" 是文字，乘 2 是重复两遍，得 77。
- ❌ `14 ⏎ 14`：第二个 print 里的 "7" 带引号，是文字，没有经过 int()。
- ❌ `77 ⏎ 77`：n 是 int("7") 的结果，已经是整数，7 * 2 得 14。

### U7 样板：U7L1 按名字查库存（字典、键和值、stock[键]）

**开场说明**：列表按位置找，字典按名字找。stock = {"奶茶": 12, "果茶": 5} 里，每一对是“名字: 数量”。stock["果茶"] 查出果茶的数量 5。

**开场示例**：
```python
stock = {"奶茶": 12,
         "果茶": 5}
print(stock["奶茶"])
print(stock["果茶"])
```

**第 1 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12,
         "果茶": 5}
print(stock["果茶"])
```

- ✅ `5`：按键“果茶”查，得到它的值 5。
- ❌ `12`：12 是奶茶的值；方括号里写的是“果茶”。
- ❌ `果茶`：查出来的是值，不是键本身。
- ❌ `1`：字典不按位置找，方括号里写的是键。

**第 2 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12,
         "果茶": 5}
name = "奶茶"
print(name, stock[name])
```

- ✅ `奶茶 12`：name 里是 "奶茶"，stock[name] 就是 stock["奶茶"]，得 12。
- ❌ `name 12`：name 是变量，显示的是它里面的文字：奶茶。
- ❌ `奶茶 5`：5 是果茶的值，奶茶的值是 12。

**第 3 题（填空）** 屏幕要显示咖啡的库存：8

```python
stock = {"奶茶": 12,
         "果茶": 5,
         "咖啡": 8}
print(stock[____])
```

- ✅ `"咖啡"`
- ❌ `咖啡`：没有引号，Python 把咖啡当变量名，报 NameError。键是文字，要带引号。
- ❌ `2`：字典不按位置找：stock[2] 找的是叫 2 的键，没有，报 KeyError。
- ❌ `"果茶"`：果茶的值是 5，不是 8。

**第 4 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12,
         "果茶": 5}
a = stock["奶茶"]
b = stock["果茶"]
print(a + b)
```

- ✅ `17`：a 是 12，b 是 5，都是整数：12 + 5 = 17。
- ❌ `奶茶果茶`：a、b 里放的是查出来的值，不是键。
- ❌ `125`：值是整数 12 和 5，不是文字，+ 是做加法。

**第 5 题（排序）** 排好顺序：查出奶茶的库存，再进货 1 杯后显示。屏幕显示：13

可选的行（打乱显示）：
```python
n = stock["奶茶"]
print(n + 1)
stock = {"奶茶": 12}
```

正确顺序：
```python
stock = {"奶茶": 12}
n = stock["奶茶"]
print(n + 1)
```

### U8 样板：U8L1 定义和调用（def、函数体、调用 welcome()）

**开场说明**：每次开门都要说“欢迎光临”。def welcome(): 给下面缩进的几行起个名字，这时它们还不会运行。写 welcome() 才是调用：调用一次，运行一次。

**开场示例**：
```python
def welcome():
    print("欢迎光临")
welcome()
welcome()
```

**第 1 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
def welcome():
    print("欢迎光临")
welcome
welcome()
```

- ✅ `欢迎光临`：第 3 行只写了 welcome，没有括号，只是提到这个名字，没有调用，函数体不会运行（也不会报错）。第 4 行 welcome() 带括号才是调用，函数体运行一次，所以只显示一次“欢迎光临”。
- ❌ `欢迎光临 ⏎ 欢迎光临`：只写名字 welcome 不算调用。调用要带括号：这段程序只有第 4 行 welcome() 一次调用，欢迎光临只显示一次。
- ❌ `报错`：只写名字不会报错：welcome 在第 1 行已经定义过，提到它没有问题，只是不会运行函数体。用到没有定义的名字才会报 NameError。
- ❌ `什么都不显示`：第 4 行 welcome() 带着括号，是调用，函数体会运行，显示“欢迎光临”。只写名字的是第 3 行，那一行什么都不做。

**第 2 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python
def welcome():
    print("欢迎光临")
welcome()
print("请点单")
welcome()
```

- ✅ `欢迎光临 ⏎ 请点单 ⏎ 欢迎光临`：函数在被调用的那一行运行：第 3 行调用 → 欢迎光临；第 4 行 → 请点单；第 5 行再调用一次 → 再显示一次欢迎光临。调用几次，函数体就运行几次。
- ❌ `欢迎光临 ⏎ 请点单`：第 5 行又调用了一次 welcome()，函数体会再运行一遍，所以欢迎光临显示两次。
- ❌ `欢迎光临 ⏎ 欢迎光临 ⏎ 请点单`：程序按顺序一行一行运行：第 3 行调用（欢迎光临），第 4 行 print（请点单），第 5 行再调用（欢迎光临）。两次调用之间夹着“请点单”。
- ❌ `欢迎光临 ⏎ 欢迎光临 ⏎ 欢迎光临 ⏎ 请点单`：def 那一行不会运行函数体，不算调用。这段程序只有第 3、5 行两次调用，欢迎光临只显示两次。

**第 3 题（填空）** 屏幕要显示：欢迎光临

```python

```

- ✅ `welcome()`
- ❌ `welcome`：只写名字、不带括号，只是提到了这个函数，没有调用它，函数体不会运行，屏幕上什么都不显示（也不会报错）。调用要带括号。
- ❌ `def welcome():`：def 是“定义”，不是“调用”。而且 def 后面必须有缩进的函数体，这里没有，会报 IndentationError（缩进错误：def 后面缺少缩进的内容）。
- ❌ `Welcome()`：大小写不同，Python 当成另一个名字。Welcome 没有定义过，会报 NameError（用到了没有定义的名字）。

### U9 样板：U9L1 菜单、订单、合计（需求拆成数据：菜单用字典、订单用列表、合计用循环累加）

**开场说明**：要做一张奶茶店小票。先把需求拆开：菜单是“名字 → 单价”，用字典；订单是点了哪几杯，用列表，同一种可以点好几杯；合计就是把订单里每一杯的单价，到菜单里查出来再加起来。

**开场示例**：
```python
menu = {"奶茶": 15}
order = ["奶茶", "奶茶"]
total = 0
for name in order:
    total = total + menu[name]
print(total)
```

**第 1 题（填空）** 菜单要能按名字查单价。屏幕显示：15

```python
menu = ____
print(menu["奶茶"])
```

- ✅ `{"奶茶": 15}`
- ❌ `["奶茶", 15]`：方括号是列表，只能按位置 0、1 取，不能按名字“奶茶”查，会报错。
- ❌ `"奶茶: 15"`：整个放进引号里只是一段文字，不能按名字查，会报错。

**第 2 题（选输出）** 点单屏运行这段程序，屏幕上会显示什么？

```python

        "果茶": 12}

         "奶茶"]
for name in order:
    print(name, menu[name])
```

- ✅ `奶茶 15 ⏎ 果茶 12 ⏎ 奶茶 15`：for name in order 走的是订单：奶茶、果茶、奶茶，一杯一轮，每轮到菜单里查这一杯的单价。奶茶点了两杯，就显示两次。
- ❌ `奶茶 15 ⏎ 果茶 12`：这是循环走菜单的结果。这里循环的是 order（订单），订单里有 3 杯，奶茶出现两次，就显示两次。
- ❌ `奶茶 ⏎ 果茶 ⏎ 奶茶`：print(name, menu[name]) 显示两样：名字和查到的单价，每行都有价格。
- ❌ `报错`：不会报错：name 每轮是订单里的一个饮品名，用变量当键查字典是可以的；三杯都在菜单里。

**第 3 题（填空）** 屏幕要显示合计：42

- ❌ `order[name]`：order 是列表，要用位置号查，不能用名字，会报 TypeError。单价在菜单字典里：menu[name]。

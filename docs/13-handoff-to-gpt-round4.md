## 一、这一轮做完了什么（课程内容、难度、XP、红心、连续天数、解锁规则都没改）

1. **手感**：反馈节奏（检查后 120ms 出结果、240ms 出统计、280ms 才能继续），减少动效时全部立即显示；防重复提交。
2. **视觉**：“墨蓝实验手账”主题、吉祥物 4 种表情、线性图标、六边形关卡节点（完成/当前/锁定/复习）、按窗口尺寸生成的流动电路背景（iPad 小窗口也看得到）。
3. **声音**：全部 Web Audio 合成，不下载音频。
   - 按键音效 A–J 十个原创“矮轴键盘”风格，**J 极简 Tap 是默认**，其余九个在“我的 → 按键音效”点一下即试听并选用，选择存在本机。
   - 答题里的六种声音（点选、放入、撤销、答对、答错、过关）都是**所选风格的同系列变化**（换音高、叠 1–3 下）。
   - 实测：点选响度十个风格相差 < 0.2 dB；同一种声音跨风格 ≤ 2.5 dB；同一风格内点选/放入/撤销 ≤ 3 dB；峰值不削波；同时最多 3 个声音，多的快速淡出。
4. **iPhone 无声的根因已找到并修了（待真机确认）**：游戏按钮原来在 pointerdown 就执行，而 iOS 只承认 touchend/click/keydown 能解锁音频；现在按钮改为真正的 click，解锁在三种事件里重试。
5. **振动**：iPhone Safari 没有 navigator.vibrate；做了四种控件的“触感测试”（普通按钮/原生开关/选项/检查按钮样式），结果要凭手感。我这边只记录点击，不宣布成功。

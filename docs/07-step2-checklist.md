## 自动测试（Claude）
`npm test` = 技术验证页 64 项 + 关卡模式 142 项，全部通过。关卡模式覆盖：
- 内容：每道题用真实 Python 运行核对（选项、填空答案、错误词块、排序题所有排列）
- 流程：开场、地图解锁、关卡弹窗、做题、答错扣心 + 原因 + 正确答案、错题回炉、通关页
- 规则：XP、红心恢复（30 分钟 1 颗、上限 5）、连续天数（同日不重复、断档重来、跨年）、红心为 0 的复习关
- 手感：检查后的时间线（120ms 揭示、280ms 可继续）、连点只计一次分、快速连点“继续”只前进一题、离开后旧回调不冒出反馈条、减少动态效果、音效 / 振动开关保存、v3 记录升级保留进度、无声音 / 无振动 / 音频创建失败时不报错、浅深配色文字对比度 ≥ 4.5:1
- 其他：退出确认、小码提示、我的页面、清除记录、旧版记录迁移、存储失败与损坏、不同屏宽

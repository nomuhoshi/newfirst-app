# 第 2 步：N01 一节完整的课 · 验收记录

## 完成标准（项目主人定）
一个从未学过的人，读完讲解，能理解例子，并独立完成小任务；退出后还能继续。

## 内容结构
| 部分 | 内容 |
|---|---|
| 讲解 1 | 输出是什么（例子：`print("你好")`） |
| 讲解 2 | 怎样使用 print：词义 /prɪnt/、括号、引号、数字、半角符号 |
| 讲解 3 | 执行顺序：从上往下一行一行执行 |
| 练习 1 | 看两行代码选输出（每个错误选项都有具体原因） |
| 练习 2 | 补全 `print()`，输出 Hi（只用内置键盘） |
| 练习 3 | 修改代码，输出两行中文（第一次切换系统键盘） |
| 小任务 | 从空白写三行：名字 / 爱好：… / 一句自我介绍 |
| 变化题 | 只在看过小任务参考答案后出现：调换前两行顺序 |

内容在 `content/n01.json`，词义在 `content/words.json`。所有例子和参考答案都由自动测试真实运行核对。

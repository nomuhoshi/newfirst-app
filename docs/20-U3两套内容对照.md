# U3 两套内容的对照（#33 预览版 8 题 vs #20/#21 已写好的 U3，共 8 关 32 题）

结论：**只保留 #20/#21 这一套**。#33 的 8 道题只在预览里试过，`content/unit3.json` 和 #20 同一路径，两个都合并会冲突；#33 不合并。#33 里有 3 处是 #20/#21 没有的，建议改进到 #20，而不是并存。写于 2026-11-04，主责：程序员 Sonnet。

## 1. 覆盖面对照

| 知识点 | #20/#21 | #33 | 谁更好 |
|---|---|---|---|
| `>` 与 `>=` 的边界 | U3L1#1（`100 >= 100` 与 `100 > 100`）、U3L1#2 填空 | 无 | #20 |
| `<` 小于 | **没有**。U3L1 只用了 `>` 和 `>=` | U3L1#1 填空、#3 | #33 |
| `==` / `!=` | U3L2#0、#1、#3；`"15" == 15` 为 False；`"vip"` 与 `"VIP"` | U3L2#0、#1、#2 | #20 更全 |

## 2. 建议在 #20/#21 里改的 3 处（不新增关卡、不改题数）

1. **U3L2#3 换掉。** 现在是 `code = "vip"; print(code == "VIP")`，只有 `==`、`!=` 两个词块，和 U3L2#1 填空是同一种题，区分度最低。换成 #33 的 `cups = 2` / `cups == 3` / `print(cups)`（答案 2；错因：选 3 是把 `==` 当成存值，选 False 是以为比较结果会自己显示）。`"vip"` 与 `"VIP"` 区分大小写这一点，已经在 U3L2#2 的 `"15" == 15` 里换了一种方式考过，可以不再单独考。
2. **U3L1 补上 `<`。** 把 U3L1#0 的 `print(total > 100)`（total = 80，False）改成 `print(total < 100)`（True），这样一关里同时有 `<`、`>=`、`>`。同时 U3L1#2 的填空保持不变。
3. **U3L1 的开场文字补一句“> 大于、< 小于”。** #20 现在的开场只提到 True/False，没有说符号名字。#33 的提示条是：“> 是‘大于’，< 是‘小于’。比较的结果只有 True 和 False 两种。”

这 3 处都只是换题或改一个符号，不改题数、XP、红心、难度、解锁。动手前需要 GPT 点头，因为 #20 是另一位的内容 PR。

## 3. #33 里**不**值得并入的题
- U3L1#0（`cups > 2` 为 True）：和 #20 的 `total > 100` 是同一种看懂题。
- U3L2#0（`size == "大杯"`）：#20 的 U3L2#1 填空已经覆盖。
- U3L2#1（`cups != 3`）：#20 的 U3L2#0 在同一道题里同时考了 `==` 和 `!=`。
- 两个排序题和 U3L1#3 的 `price < 10`：知识点已被覆盖。

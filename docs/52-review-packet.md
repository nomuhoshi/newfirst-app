### 1.2 最长题 14 行（L6 Q4）

**U9L6 Q4（predict）题面**：修好之后，再用刚才露馅的订单（两杯奶茶）跑一遍，并算上优惠。屏幕上会显示什么？

```python
def bill(order, menu):
    total = 0
    for name in order:
        total += menu[name]
    return total
def discount(t):
    if t >= 30:
        return t - 5
    return t
menu = {"奶茶": 15,
        "果茶": 12}
order = ["奶茶", "奶茶"]
t = bill(order, menu)
print(discount(t))
```

| 选项 | 对错 | 解析 |
|---|---|---|
| `25` | ✔ | bill 现在把两杯都加上：15 + 15 = 30；30 满 30，discount 交回 25。修完用露馅的那张订单再试一次，确认真的修好了。 |
| `30` | ✗ | t 是 30，还要过 discount：30 正好满 30，减 5，是 25。 |
| `15` | ✗ | 15 是修之前的结果（每轮清零，只剩一杯）。total = 0 已经挪到循环外面，两杯都算上了。 |
| `10` | ✗ | discount 只在满 30 时减 5，不会把两杯各减 5。 |

**问题**：矮屏（390×450）要滚动才能看完代码。A：保留，接入预览后验；B：把 discount 的定义挪进讲解，题里只留 bill 和调用（约 9 行）。

### 1.3 UnboundLocalError 干扰项（L6 Q3）

**U9L6 Q3（pick）题面**：怎么改，bill 对各种订单都算对？（拿一杯、两杯、三杯的订单都核对过）

```python
def bill(order, menu):
    for name in order:
        total = 0
        total += menu[name]
    return total
```

| 选项 | 对错 | 解析 |
|---|---|---|
| `把 total = 0 挪到 for 上面` | ✔ | 清零只在开始时做一次：先 total = 0，再循环把每一杯加进去，最后交回。一杯、两杯、三杯都对。 |
| `把 total += menu[name] 改成 total = total + menu[name]` | ✗ | 两种写法意思一样，total = 0 还在循环里，每轮照样清零，两杯以上还是错。 |
| `删掉 total = 0` | ✗ | total 一开始没有值，第一轮就要往上加，会报 UnboundLocalError（和 NameError 同类：用到了还没有值的名字）。 |
| `把 return total 也缩进到循环里` | ✗ | 第一轮就交回了，只算第一杯；两杯以上还是错。 |

**问题**：“删掉 total = 0”的真实结果是 UnboundLocalError，前面单元没教过这个名字，解析里说明了“和 NameError 同类”。A：保留（真实报错，顺带认识）；B：换成别的干扰项（例如“把 total = 0 改成 total = 1”）。

### 1.4 和样板关的有意重复（L3 Q2、L6 Q2）

**U9L3 Q2（pick）题面**：AI 把条件写成了 if t > 30:。规则是满 30 减 5，正好 30 也减。用哪个合计调用 discount，能看出它和规则不一致？

```python
def discount(t):

        return t - 5
    return t
```

| 选项 | 对错 | 解析 |
|---|---|---|
| `discount(30)` | ✔ | 规则：30 要减成 25；AI 写的 > 30 不认 30，交回 30。正好卡在分界线上的这一个，才测得出来。 |
| `discount(29)` | ✗ | 29 不满 30：规则不减，AI 的程序也不减，都是 29，一致。 |
| `discount(42)` | ✗ | 42 超过 30：规则和程序都减 5，都是 37，一致。比 30 大的数，> 和 >= 结果一样。 |
| `discount(15)` | ✗ | 15 不满 30：都不减，都是 15，一致。 |

**U9L6 Q2（pick）题面**：规则：合计是订单里每一杯单价相加。用哪张订单测试，能看出 AI 的 bill 和规则不一致？

| 选项 | 对错 | 解析 |

| `["奶茶", "奶茶"]` | ✔ | 规则要 30；AI 的 bill 每轮清零，只剩最后一杯，交回 15。至少两杯，前面的被清掉才看得出来。 |

## U7L1 按名字查库存（字典、键和值、stock[键]）

**讲解**：库存按名字记：奶茶 12 杯、果茶 5 杯。列表靠位置找（cups[0]），字典（英文叫 dict）靠名字找：stock = {"奶茶": 12, "果茶": 5}。花括号里是一对一对的“键: 值”：键是名字（"奶茶"），值是对应的数量（12），冒号连着，逗号隔开。取值时在方括号里写键：stock["果茶"] 得到 5，写的是名字，不是第几个。键要和字典里写的一模一样；查一个字典里没有的键，会报 KeyError。注意 print(stock) 显示的字典，文字外面是单引号：{'奶茶': 12, '果茶': 5}，Python 习惯这样显示。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
print(stock)
print(stock["果茶"])
```
真实输出：`{'奶茶': 12, '果茶': 5} ⏎ 5`

### U7L1-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
print(stock["果茶"])
```
真实输出：`5`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `5` | ✅ 正确 | stock["果茶"] 按键“果茶”查，对应的值是 5。 |
| `12` | ❌ | 12 是奶茶的数量。方括号里写的是“果茶”，查到的是果茶的值 5。 |
| `果茶` | ❌ | 方括号里写的是键，查出来的是这个键对应的值（5），不是键本身。 |
| `1` | ❌ | 字典不按位置找。cups[1] 是列表的写法；字典方括号里写的是键，这里是 "果茶"。 |

提示：stock[键] 查出这个键对应的值。

### U7L1-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
name = "奶茶"
print(name, stock[name])
```
真实输出：`奶茶 12`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `奶茶 12` | ✅ 正确 | name 里放着文字 "奶茶"，stock[name] 就是 stock["奶茶"]，值是 12；print 用逗号隔开，中间补一个空格。 |
| `name 12` | ❌ | name 没有引号，是变量，print 显示的是它里面的文字：奶茶。 |
| `奶茶 5` | ❌ | 5 是果茶的数量；name 里是“奶茶”，奶茶对应的是 12。 |
| `奶茶 stock[name]` | ❌ | stock[name] 没有引号，不是文字，是要 Python 去查的：查出来是 12。 |

提示：方括号里可以放变量：变量里是什么键，就查什么键。

### U7L1-Q3（填空）屏幕要显示：8

```python
stock = {"奶茶": 12, "果茶": 5, "咖啡": 8}
print(stock[{0}])
```
标准答案：`"咖啡"`；期望输出 `8`

| 词块 | 真实运行 | 说明 |
|---|---|---|
| `"咖啡"` | 显示 8 | ✅ 正确 |
| `咖啡` | 报错 NameError | 咖啡没有引号，Python 会把它当成变量名去找，找不到，会报 NameError。键是文字，要写成 "咖啡"。 |
| `2` | 报错 KeyError | 字典不按位置找：stock[2] 是在找一个叫 2 的键，字典里没有，会报 KeyError。咖啡虽然写在第 3 个，也不能用 2 去取。 |
| `"果茶"` | 显示 5 | stock["果茶"] 是 5，不是 8。8 是咖啡的数量。 |

提示：要的是咖啡的数量：方括号里写键 "咖啡"，注意带引号。

### U7L1-Q4（读报错选择）查库存时出了报错。最后一行 KeyError: '咖啡' 合起来是在说什么？

```python
stock = {"奶茶": 12, "果茶": 5}
print(stock["咖啡"])
```
展示给学生的报错（真实运行，和 CPython 一致，不含 ^ 箭头）：
```
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(stock["咖啡"])
KeyError: '咖啡'
```

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| 字典里没有叫 '咖啡' 的键 | ✅ 正确 | KeyError 就是“键错误”：用来查的键，字典里没有。这个字典只有 "奶茶" 和 "果茶"，没有 "咖啡"，所以查不到。冒号后面的 '咖啡' 就是那个找不到的键。 |
| 用到了一个还没有定义的变量名 | ❌ | 那种错误叫 NameError，信息里写 name '…' is not defined。这里的 "咖啡" 带着引号，是文字，不是变量名，最后一行写的是 KeyError。 |
| 列表的下标超出了范围 | ❌ | 那种错误叫 IndexError，是列表（比如 cups[2]）位置越界。这里是字典，没有“第几个”，最后一行写的是 KeyError。 |
| 文字和整数放在一起用 + 接了 | ❌ | 那种错误叫 TypeError。这行代码里没有 +，最后一行写的是 KeyError。 |

提示：最后一行：冒号前面是错误类型，冒号后面是具体信息——这里就是找不到的那个键。

## U7L2 改库存（给已有的键写新值）

**讲解**：卖掉了东西，库存要改。给已经有的键写新值：stock["果茶"] = 9，字典里果茶的数量就换成 9——是替换旧值，不是加上去。想在旧数量的基础上改，右边先查出旧值再算：stock["奶茶"] = stock["奶茶"] - 1，Python 先算右边（12 - 1 得 11），再把 11 存回奶茶。只写 stock["奶茶"] - 1 不行：这只是算了一下，没有存回去，库存没变。改的是字典本身，改完之后再去查，查到的就是新值。这一关只改字典里已经有的键。

讲解示例程序：
```python
stock = {"奶茶": 12, "果茶": 5}
stock["果茶"] = 9
stock["奶茶"] = stock["奶茶"] - 1
print(stock)
```
真实输出：`{'奶茶': 11, '果茶': 9}`

### U7L2-Q1（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
stock["果茶"] = 9
print(stock)
```
真实输出：`{'奶茶': 12, '果茶': 9}`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `{'奶茶': 12, '果茶': 9}` | ✅ 正确 | stock["果茶"] = 9 把果茶的值换成 9，奶茶没动。 |
| `{'奶茶': 12, '果茶': 14}` | ❌ | = 是“换成”，不是“加上”：5 被换成了 9，不是 5 + 9。 |
| `{'奶茶': 12, '果茶': 5}` | ❌ | 第 2 行已经运行过了：果茶的值被换成了 9，print 显示的是改完之后的字典。 |
| `{'奶茶': 9, '果茶': 5}` | ❌ | 改错了名字：第 2 行方括号里写的是 "果茶"，被换成 9 的是果茶，奶茶没动。 |

提示：stock[键] = 新值：把这个键原来的值换成新值。

### U7L2-Q2（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
stock["奶茶"] = stock["奶茶"] - 1
print(stock["奶茶"], stock["果茶"])
```
真实输出：`11 5`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `11 5` | ✅ 正确 | 第 2 行先算右边：stock["奶茶"] 是 12，12 - 1 得 11，存回奶茶；果茶没动，还是 5。 |
| `12 5` | ❌ | 第 2 行把算出来的 11 存回了奶茶，所以后面查到的是 11，不是原来的 12。 |
| `1 5` | ❌ | 右边是 stock["奶茶"] - 1，用的是奶茶原来的数量 12 减 1，得 11，不是 1。 |
| `11 4` | ❌ | 第 2 行只改了奶茶。果茶这个键没有动，还是 5。 |

提示：等号右边先算，再把结果存回左边的键。

### U7L2-Q3（排序）排好顺序。屏幕先显示“卖前 12”，再显示卖掉 3 杯之后的“卖后 9”

标准顺序（打乱后让学生排）：
```python
stock = {"奶茶": 12}
print("卖前", stock["奶茶"])
stock["奶茶"] = stock["奶茶"] - 3
print("卖后", stock["奶茶"])
```
真实输出：`卖前 12 ⏎ 卖后 9`；可接受的排列共 1 种（穷举所有 24 种排列核对）。提示：先有字典；改之前先看一次；再改；改完再看一次。


### U7L2-Q4（选输出）点单屏运行这段程序，屏幕上会显示什么？

```python
stock = {"奶茶": 12, "果茶": 5}
stock["果茶"] - 1
print(stock["果茶"])
```
真实输出：`5`

| 选项 | 对错 | 错因 / 解释 |
|---|---|---|
| `5` | ✅ 正确 | 第 3 行 stock["果茶"] - 1 只算出了 4，没有存回字典，随后就丢掉了，不会报错，字典没变。 |
| `4` | ❌ | 算出了 4，但没有写 stock["果茶"] = …，没有存回去，字典里还是 5。 |
| `报错` | ❌ | stock["果茶"] - 1 单独写一行不会报错：Python 算完就丢掉结果，库存不变。 |

提示：想改库存，要写成 stock[键] = 新值；只做计算，字典不会变。

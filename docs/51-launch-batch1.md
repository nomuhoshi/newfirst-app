2. 快进推送：`git push origin 7fcea46…:refs/heads/main`（不用 `--force`；不是快进就会被拒）。
3. 看 main 上的 `Test and deploy`：build、mobile webkit、mobile chromium 全绿后 deploy 才会跑。
4. 核对 Pages 部署记录的提交 = 推上去的提交；线上「我的」页的应用版本时间和这次构建一致。
5. 失败处理：CI 不绿就不会部署，正式站保持原样；已部署后发现严重问题，用 `git revert` 生成回退提交再推（不 force、不改历史），回到 `70cbb7d` 的内容。

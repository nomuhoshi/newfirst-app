## 3. 验收步骤（每步在记录表里填结果）

**P3-01 打开入口与版本核对**：入口能正常打开；“我的 → 账号”页的测试入口信息显示 `p3-code` 和提交 `94a67e8`。

**P3-02 编辑器与自带键盘（重点，进度码 A）**：地图 → U3L5 → 开始。先答前 3 题（点选题，随便答；**第一次答错会扣 1 颗心**，这是正常的），到第 4 题（改代码题，有编辑区和“运行 / 检查”）。
- 点编辑区：应出现页面自带的键盘（不是 iOS 系统键盘），编辑区不被遮住。
- 用自带键盘输入：字母、数字、引号 `"`、括号 `()`、冒号 `:`、回车、缩进、退格，各试几次。把代码改成一行 `print("总价", 3 * 5)`。
- 点“运行”：应显示真实输出 `总价 15`，**不判对错、不扣红心、不加 XP**。
- 滚动页面：编辑区、题面、反馈条没有被键盘挡住或错位。如有“切换系统键盘”按钮，切过去再切回来，输入仍正常。
- **做完这一步要恢复题目原来的错误代码**：点“重新开始”→ 弹窗里再点“重新开始”，编辑器应恢复成题目给的初始代码（`else total < 100:` 那一版），再继续下一步。

**P3-03 答错再改对（进度码 A，接着 P3-02 的同一道题）**：
1. 编辑器是初始（错误）代码，直接点“检查”：应显示“不对哦”和每组测试的对比，**红心再扣 1 颗**，XP 不变。
2. 点“继续”：**不会马上回到这道代码题**——答错的题会排到最后，所以先重做之前答错的点选题，**最后**才回到这道代码题。
3. 回到代码题后，把错误代码改对（`else total < 100:` 改成 `else:`）→ “检查”→ 反馈“答对了”→ “继续”→ 通关页。
4. 本关 XP 共 +50（4 题 ×10 + 通关 10），红心共少 2 颗（前面答错一次普通题 + 这道代码题答错一次）。

**P3-04 U4L6 超时后继续作答（重点，进度码 B）**：清除 → 粘贴 B。地图 → U4L6 → 开始，答完前面的点选题，到代码题（题面说“停不下来”）。
- **不改代码**直接点“检查”：约 5 秒后提示“运行时间太长，已停止……这次不算作答，不扣红心，代码已保留”；红心数量**不变**、没有“不对哦”反馈条，“检查”按钮恢复可点。再点一次“检查”（仍不改）：同样提示，页面不卡。
- 点“运行”，约 1 秒后点“停止”：应显示“已停止”，页面不卡；点“重新开始”恢复初始代码。再试一次：点“运行”写一行 `print("OK")` 后运行，应正常输出 OK（先把代码改成这行，试完再“重新开始”）。
- 把代码改对（在 `total = total + x` 下面加一行 `x = x + 1`）→ “检查”→ 答对（+10，红心不变）。

**P3-05 U5L2 报错显示（重点，进度码 C）**：清除 → 粘贴 C。地图 → U5L2 → 开始，到代码题。**不改代码**点“检查”：应看到 `IndexError（第 N 行）：list index out of range` 和中文说明“索引错误：取的位置超出了列表的范围”（每组测试各一份）；这是首次作答，**红心扣 1 颗**。继续后回到这道题，把 `cups[1]` 改 `cups[0]`、`cups[len(cups)]` 改 `cups[-1]` → “检查”→ 答对。

**P3-06 变式流程（重点，进度码 A 的 U3L6）**：完成 P3-03 后 U3L6 就是下一个“当前”关。地图 → U3L6 → 开始，到第 3 题（改代码题）：
- 点“提示”（小码头像）：先后看到“提示 1/2”“提示 2/2”；再点一次：问“要看参考解法吗？”，写明“之后要再做一道变化题”。选“看参考解法”→ 能看到参考代码。
- 把原题改对（可照抄）→ “检查”：应**不结算**（没有“答对了”条，XP 和红心不变），页面进入“变化题”（有“变化题”标记和新题面）。
- 变化题故意答错：提示“变化题：不扣红心，可以继续改”，红心不变。
- 变化题答对：这时才结算，**只加一次 +10**；之后继续到通关，本关 XP 共 +50（不因为看了解法而多加）。

**P3-07 没有变化题的题（重点，进度码 D）**：清除 → 粘贴 D。地图 → U5L5 → 开始，到代码题（写代码题），照提示写对 → “检查”→ 答对（+10）后**没有**变化题，直接继续 / 通关（共 +50）。

**P3-08 退出再进入：草稿与累计记录（进度码 C，接着 P3-05 的 U5L2 做）**：本项只验证**草稿**和**累计记录**，不要求“某一题的答题结果”被记住（应用只保存草稿和累计进度）。
1. 清除 → 粘贴 C → U5L2 → 到代码题 → 把代码写成一半（例如只改一行，**不点检查**）→ 记下此刻的 XP、红心（“我的”页）。
2. 切到别的 App / 锁屏 20 秒 → 回来：代码还在。
3. **完全关掉** Safari 这个标签页（或从多任务里划掉主屏幕 App）→ 重新打开入口：“我的”页里的 XP、红心、已完成关卡数**和关掉前完全一样**（打开 / 刷新本身**不会加分**）。
4. 重新进入 U5L2：**会从第 1 题重新开始**（这是预期，不是丢进度）；走到同一道代码题时，**写了一半的草稿仍在**。
5. 答对这一关再重玩一遍属于“复习”，XP 规则不在本次验收范围。

**P3-09 主屏幕模式**：在 Safari 里“分享 → 添加到主屏幕”，从图标打开（**这是单独的存储，要重新清除并粘贴进度码**，见第 2 节）。在主屏幕模式下重复 P3-02（键盘）、P3-04（超时，进度码 B）、P3-05（报错，进度码 C）至少各做一次，并做一次 P3-08 的“完全关掉再打开”。

**P3-10（可选）离线**：先在线做过一次“检查”（让 Python 加载完），再开飞行模式：再点“检查”，结果应仍能判分，或明确提示“Python 环境暂时不可用，这次不算作答”，**不扣红心**。

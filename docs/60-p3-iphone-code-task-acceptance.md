## 3. 验收步骤（每步在记录表里填结果）

**P3-01 打开入口与版本核对**：入口能正常打开；“我的 → 账号”页的测试入口信息显示 `p3-code` 和提交 `94a67e8`。

**P3-02 编辑器与自带键盘（重点）**：地图 → 单元 3 → “U3L5”→ 开始。做到第 4 题（改代码题，有编辑区和“运行 / 检查”）。
- 点编辑区：应出现页面自带的键盘（不是 iOS 系统键盘），编辑区不被遮住。
- 用自带键盘输入：字母、数字、引号 `"`、括号 `()`、冒号 `:`、回车、缩进（空格 / Tab 键）、退格，各试几次。输入一行 `print("总价", 3 * 5)`。
- 点“运行”：应显示真实输出，**不判对错、不扣红心、不加 XP**。
- 滚动页面：编辑区、题面、反馈条没有被键盘挡住或错位。
- 如有“切换系统键盘”之类按钮，切过去再切回来，输入仍正常。

**P3-03 改对并检查**：把 U3L5 的错误代码改对（`else total < 100:` 改成 `else:`）→ “检查”→ 应显示答对（反馈条“答对了”）→ “继续”。再故意答错一次（把代码改坏再“检查”）：应显示“还没通过”和每组测试的对比，红心 −1，这道题稍后再出现一次。

**P3-04 U4L6 超时后继续作答（重点）**：单元 4 → “U4L6”→ 开始，做到代码题（题面说“停不下来”）。
- **不改代码**直接点“检查”：约 5 秒后提示“运行时间太长，已停止……这次不算作答，不扣红心，代码已保留”；红心数量**不变**、没有“不对哦”反馈条，“检查”按钮恢复可点。
- 再点一次“检查”（仍不改）：同样提示，页面不卡。
- 点“运行”，约 1 秒后点“停止”：应显示“已停止”，页面不卡；再点“运行”写一行 `print("OK")`：正常输出 OK。
- 把代码改对（在 `total = total + x` 下面加一行 `x = x + 1`）→ “检查”→ 答对。

**P3-05 U5L2 报错显示（重点）**：单元 5 → “U5L2”→ 开始，做到代码题。**不改代码**点“检查”：应看到 `IndexError（第 N 行）：list index out of range` 和中文说明“索引错误：取的位置超出了列表的范围”（每组测试各一份）。把 `cups[1]` 改 `cups[0]`、`cups[len(cups)]` 改 `cups[-1]` → “检查”→ 答对。

**P3-06 变式流程（重点）**：回到 U3L5（重玩）→ 第 4 题：
- 点“提示”（小码头像）：先后看到“提示 1/2”“提示 2/2”；再点一次：问“要看参考解法吗？”，写明“之后要再做一道变化题”。选“看参考解法”→ 能看到参考代码。
- 把原题改对（或照抄）→ “检查”：应**不结算**（没有“答对了”条，XP 和红心不变），页面进入“变化题”（有“变化题”标记和新题面）。
- 变化题故意答错：提示“变化题：不扣红心，可以继续改”，红心不变。
- 变化题答对：这时才结算，答对一次；之后继续到通关。

**P3-07 没有变化题的题**：单元 5 → “U5L5”→ 做到代码题（写代码题），照提示写对 → “检查”→ 答对后**没有**变化题，直接继续 / 通关。

**P3-08 退出再进入后的进度与草稿（重点）**：
- 在某道代码题里写一半代码（不点检查）→ 切到别的 App / 锁屏 20 秒 → 回来：代码还在。
- 完全关掉 Safari 这个标签页（或从多任务里划掉主屏幕 App）→ 重新打开入口 → 进入同一关同一题：写了一半的代码仍在（草稿保留），“我的”页里的 XP、红心、已完成关卡没有丢。
- 答对一题后再关掉重开：这一题的结果还在，不会被重复加分。

**P3-09 主屏幕模式**：在 Safari 里“分享 → 添加到主屏幕”，从图标打开（**这是单独的存储，进度要重新粘贴进度码**，见第 2 节）。在主屏幕模式下重复 P3-02、P3-04、P3-05 至少各做一次，并做一次 P3-08 的“完全关掉再打开”。

**P3-10（可选）离线**：先在线做过一次“检查”（让 Python 加载完），再开飞行模式：再点“检查”，结果应仍能判分，或明确提示“Python 环境暂时不可用，这次不算作答”，**不扣红心**。

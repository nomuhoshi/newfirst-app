# 复现「主脚本下载成功（HTTP 200），但页面仍白屏」

更新：2026-11-05（Sonnet2）。只在 Chromium 本地预览复现；WebKit、微信内置浏览器（X5 / WKWebView）没验。

## 复现步骤
```
npm run build
node scripts/repro-blank-screen.mjs dist [截图目录]
```
脚本起本地服务器托管 `dist/`，把 `assets/main-*.js` 的响应换成（都返回 HTTP 200）：
1. 语法错误：`const = ;`
2. 启动时异常：真实主程序前面加一句 `throw new Error(...)`（模块一执行就报错，什么都没渲染）
3. 启动后异步异常：真实主程序正常渲染，1.5 秒后抛出未处理的 Promise 拒绝

对每一种，先开应用页（390×844 触屏模拟），记录兜底提示和控制台；再在同样条件下开 `access-test.html` 点“开始测试”，记录诊断页的结论。

## 结果（Chromium）
| 情况 | 应用页 | 控制台 | 诊断页 |
|---|---|---|---|
| 0 对照 | 正常显示“你好，我是小码！” | 无错误 | 主程序 ✅，结论“已执行的检查通过（7 项）…主程序能不能解析、执行，这个页面没有验证” |
| 1 语法错误 | 约 1.9 秒出现“页面没有正常加载”；`#app` 为空；“给开发者的信息”里有 `Uncaught SyntaxError: Unexpected token '='` | `Uncaught SyntaxError: Unexpected token '='` | **主程序 ✅（200，9 字节）；0 项失败；结论同对照**（没发现问题） |
| 2 启动时异常 | 同上，约 1.9 秒；信息里有 `Uncaught Error: 模拟：启动时异常` | `Uncaught Error: 模拟：启动时异常` | **主程序 ✅（200，223300 字节）；0 项失败；结论同对照** |
| 3 启动后异步异常 | 页面正常显示，没有提示（兜底只管“没渲染出内容”） | `模拟：启动后异步异常`（未处理的 Promise 拒绝） | 同对照（没发现） |

## 结论
- 应用页：情况 1、2 都有兜底提示，也带着错误信息；情况 3 页面已渲染，不属于白屏。
- 缺口 A（诊断页）：诊断页只能证明“文件拿到了”，**看不出主程序解析或执行失败**。情况 1、2 在诊断页里和正常完全一样；只靠结论里的那句提示，用户和开发者都可能忽略。
- 缺口 B（应用兜底文案）：脚本报错（语法错误 / 启动异常）时，兜底提示仍把“网络不稳定”排第一。错误信息只在小字“给开发者的信息”里。

## 待项目主人拍板（拍板前不实现）

2. **首次运行跳过第一关的介绍卡**，把故事句挪到第 1 题顶部（只影响第一次，之后照旧）。
3. **第 1 题答错是否扣红心**。按现规则会扣，新人第一题就掉心体验差。这是锁定规则，本稿不改，只提出。建议：首次运行的第 1 题不扣心、XP 照常。

## 一、新手流程：首次打开 → 完成第一题（目标 30–60 秒，4 次点击）

| 屏 | 时间 | 用户点哪里 | 内容 |
|---|---|---|---|
| A 欢迎 | 0–8 秒 | ①「开始第一题」 | 碎碎（纸）+ 标题「点一点，学会 Python」+ 小字「每关约 2 分钟 · 全程点选 · 免费」。次要入口「已有账号？登录」在账号功能上线后才显示，不挡主按钮。**原 3 屏合成 1 屏，去掉翻页圆点。** |
| B 第一题 | 8–35 秒 | ② 选一个答案 ③「检查」 | 直接进入 U1L1 第 1 题（predict）。顶部故事条：「奶茶店要一块点单屏。先让屏幕显示文字。」碎碎跳到代码卡右上角**变成玻璃**，气泡 2.5 秒：「碰到什么我就变成什么。现在是玻璃，帮你看穿代码。」停留 8 秒未作答，气泡再出：「卡住了就点我。」 |
| C 反馈 | 35–45 秒 | ④「继续」 | 答对：绿条「答对了 +10 XP」+ 解释；碎碎回到纸，庆祝。答错：红条「差一点」+ 解释；碎碎碰到按键**变成橡胶**弹两下，气泡「弹回来，再看一眼引号。」 |
| → | | | 点「继续」进第 2 题，从此是普通关卡流程。`state.onboarded = true` 在第 1 题提交时写入（中途关掉 App，下次直接到地图，不重放欢迎）。 |

不做：问卷、目标选择、通知授权、注册墙、付费提示。通知等系统权限请求一律放在第一关结束之后（见 `docs/research/duolingo.md` §1）。

### 流程验收
- 从冷启动到看到第 1 题反馈：点击 ≤ 4 次；新用户实测 ≤ 60 秒。
- 欢迎屏无任何系统弹窗；不登录可一路学完第一关。
- 第 1 题的对错仍由颜色 + 文字 + 图标表达，**不靠碎碎的材质**传达对错。
- 中途退出再打开：不再显示欢迎屏。
- `prefers-reduced-motion` 下，碎碎跳上代码卡改为原地淡入，无弹跳。

## 二、碎碎变身规则（一页）

### 1. 基本形象（纸，本体）
「碎碎」是记录卡上撕下来的一片：沿用小码的折角卡轮廓，**底边改成撕边**（锯齿），这是唯一的新特征，也是名字的来源。暖白主体、墨蓝括号眼睛、铜橙折角、两只短脚，表情仍是开心 / 思考 / 陪伴 / 庆祝四种。viewBox 100×100 不变。

### 2. 变身时永远保留（识别锚点）
1. 轮廓：左上圆角、右上折角、底边撕边、两只短脚——位置和比例不动。
2. 括号眼睛和嘴的**形状与位置**（四种表情照常可用）。眼睛颜色可在墨蓝 / 暖白间切换，保证对主体 ≥ 3:1。
3. 大小：变身不改变尺寸，只允许动效中短暂缩放。

### 3. 只改变这些
主体填充、描边粗细、高光 / 纹理、折角处理、动效。

### 4. 三种材质

| | 玻璃 | 橡胶 | 软木 |
|---|---|---|---|
| 碰到什么 | 代码卡（屏幕） | 按键（答题后的「继续 / 检查」键） | 软木板（错题本、复习关、「我的学习」） |
| 学习含义 | 看穿代码：思考、提示 | 弹回来：答错后再试，不惩罚 | 钉住：收集错题、复习 |
| 主体 | 半透明（约 35%），**能看见身后的代码** | 不透明哑光，暖铜色，边角更圆鼓 | 浅棕底 + 深色斑点纹理 |
| 描边 | 细（1.5），墨蓝浅色 | 粗（4），圆角接头 | 中（2.5），深棕 |
| 标志细节 | 左上两道斜高光 | 底部一道阴影，像被压扁过 | 折角处一枚铜橙图钉 |
| 折角 | 透明，只留铜橙细边 | 变成卷边，同色更深 | 保持铜橙，被图钉钉住 |
| 变身动效 | 一道亮光从上往下扫过，400 ms | 压扁再弹起两次（scaleY .85→1.08→1），500 ms | 从上方落下、图钉「咔」一下、轻微倾斜 −3°，300 ms |
| 眼睛颜色 | 跟随页面文字色 | 浅色：墨蓝；深色：暖白 | 浅色：墨蓝；深色：暖白 |

**黑白也要分得清**：玻璃靠高光和透出的背景，橡胶靠粗边和压扁动作，软木靠斑点和图钉。不能只靠颜色区分。

### 5. 行为规则
- 同一时刻只有一种材质。离开触发它的场景（下一题、关闭弹层）就回到纸。
- 答对庆祝永远是**纸 + 火花**，不变身。材质不表示对错。
- 每种材质**第一次出现**时配一句台词解释它，之后不再解释（本地记一个标志）。
- 每题最多变身 1 次；变身动画不阻挡点击。
- 减少动态效果开启时：直接切换材质，无动画。
- 同一关里提示按钮（思考）用玻璃；错题回炉入口和复习关用软木。

### 6. 玩家第一次在哪碰到
| 顺序 | 场景 | 台词 |
|---|---|---|
| 初见（纸） | 欢迎屏 | 无台词，只有标题 |
| 第一次变身（玻璃） | 第 1 题，跳上代码卡 | 「碰到什么我就变成什么。现在是玻璃，帮你看穿代码。」 |
| 橡胶 | 第一次答错 | 「弹回来，再看一眼。」 |
| 软木 | 第一关结束有错题时，或首次打开「我的学习」 | 「错题我先钉在这儿，等会儿再来。」 |

### 可点原型的验收
1. iPhone 竖屏打开，`欢迎 → 第一题 → 反馈` 4 次点击走完。
2. 第 1 题加载时碎碎跳上代码卡变玻璃；选错并检查后变橡胶弹两下；`#cork` 里落到软木板并被钉住。三种都能亲手触发。
3. 每种材质的首次台词只出现一次；切回该状态不重复。
4. 黑白截图里三种材质可分辨；浅色 / 深色都正常。
5. 色值、字体与 `src/game.css` 一致，没有新增主色。

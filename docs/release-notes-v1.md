# 碎片编程 v1.0.0

发布：2026-11-27。面向使用者的变化和已知限制；工程细节见仓库 `docs/`。

> **验收状态（如实）**：自动化测试（Chromium + WebKit）和线上核对全部通过；**iPhone 真机尚未验收**（Safari 存档保持、主屏幕搬迁、第 7 单元长代码块、声音），按老大指示先发布、真机核查随后补做。

## 这一版有什么

- **49 关、205 道题**：第 1–7 单元——奶茶店点单屏、文字与长度、比较与判断、循环、列表与序列、类型与报错（含读报错）、字典。三种题型：选输出、填空、排序。
- **多邻国式闯关**：红心、XP、连续天数、通关结算、随机练习。
- **真 Python**：点“运行”后在浏览器里运行（首次需联网下载运行环境，几秒到几十秒）；判分题不依赖它，离线也能做。
- **离线可用**：联网打开一次后，地图和全部课程离线可看；版本更新会提示刷新。
- **进度安全**：多个标签页同时学习不会互相覆盖；导出进度文件、复制进度码，可在 Safari 与主屏幕 App 之间搬进度；存储异常有提示。
- **隐私**：不收集个人信息，学习记录只存在这台设备。
- 手机优先：点选为主，触控区域不小于 44px，支持减少动态效果，音效可关。

## 这一版没有

- **云端账号与跨设备同步**：暂未开通（“我的”页写明“云端暂未开通”）。
- **写代码 / 改代码题**：未开放。
- **第 8 单元起（函数、小项目）**：地图上显示“即将推出”。

## 已知限制

- iPhone 的 Safari 没有网页触感（振动）；这是平台限制。
- 学习记录只保存在这台设备的这个入口里：**Safari 和主屏幕 App 是两份独立存储**，换入口要先“复制进度码”再粘贴；清除网站数据、无痕模式会丢记录。Safari 对约 7 天不用的网站可能清理数据，建议添加到主屏幕并定期备份。
- 退出关卡不记答题位置，下次从第 1 题开始（已得 XP、已扣红心保留）。
- 系统要求（推断）：做题 iOS 15 起；“运行结果”需要 iOS 16.4 起。
- **以下尚未在 iPhone 真机验收**（自动化测试通过不等于真机没问题）：Safari 存档保持、主屏幕与 Safari 之间的搬迁、第 7 单元长代码块排版、声音。
